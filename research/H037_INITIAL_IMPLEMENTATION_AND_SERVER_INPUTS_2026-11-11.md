## 1. 实现范围

计划由 `scripts/run_h037_initial.py` 从共同前缀分别运行普通 LRU 与候选交接分支。候选在同组、已绑定 parent 的 victim 被清零前，用当前 W0、parent 和 victim local 的有效策略重算完整动作分布，按固定有界优化拟合新的 parent；补偿驻留 local，经真实 actor codec 往返后检查 victim、旧 prior 与驻留行为，条件不满足则回退。源代码以现行实现为准，门槛和完整包预算须先确定。

`src/online_rl/h037_evidence.py` 提供按 slot、generation、task、group 与 parent version 标识的有界在线观测缓存。该缓存来自环境实际交互，不预装目标测试数据；重算教师时使用原始观测副本，并按当前槽修正 route。样本不足、身份不匹配或其他必要条件不满足时不能凭空补样本。

重点文件：

- `scripts/run_h037_initial.py`：受控导航流的初版入口。
- `src/online_rl/h037_candidate.py`：行为教师、KL 拟合、resident 补偿与 codec 后验收。
- `src/online_rl/h037_evidence.py`：有界在线观测及身份。
- `src/online_rl/h037_integration.py`：淘汰前控制与事务集成。
- `tests/test_h037_initial.py`：供远端执行的合成正确性检查；不进行环境交互。
- `configs/h037_initial.example.json`：示例配置；尚未设定预算和行为阈值，原样运行应拒绝。
- `research/V2_ALGORITHM_STRUCTURE_REVIEW_HANDOFF_2026-11-10.md`：研究问题、接口背景与审查清单。

以上新文件不改变历史 E161–E165 已冻结记录。已有普通训练 runner 不会因为增加此入口就自动启用 H037。

## 2. 需要哪些 dataset 和其他输入

| 输入 | 路径／来源 | 用途 | 是否需要外部下载 |

| 源数据与模型元信息 | `data/pretrain_source.json`、`data/foundation.json` | 记录来源、训练与历史文件身份；不是本次候选拟合的教师标签 | 无需另外下载；应与实际文件哈希独立核对 |
| 在线观测证据 | 本次导航环境在实际交互中生成，按槽位容量持久保存 | victim 拟合、旧 prior 保护、resident 验收；必须发生在淘汰前 | 不需要预先下载；必须计入环境交互与 learner 容量 |

| 代码与环境 | 受控项目中的精确源码、`configs/c1.json`、`configs/storage_decision.json`、本轮配置、`requirements-lock.txt` 所对应环境 | 确定策略、依赖与运行身份 | 使用已经批准的项目环境，不自行升级依赖 |

4. 分别审查教师路由、时间切分、编码后的比较基线、resident 优化器状态、失败回退、checkpoint 恢复、实际完整包字节与事件账本。

涉及研究实现的合成、冒烟和正确性检查，以及实际实验，均需要在指定远端受控环境执行。本会话没有连接 SSH，也没有在本机运行这些检查。脚本中的 CPU/墙钟保护只覆盖指定进程和计时范围；需要外部受控监督来涵盖启动开销、总输出／缓存／临时空间及完整 campaign，不能把内部上限当成全资源审计。
