## 接受的方法与必须明确的交付

接受设计提案第 4–6 节的教师、逐来源归一化、固定 lambda=0/1、单次 1e-4 ridge、新来源均值初始化、L-BFGS 上限和原新训练 KL 接收过滤。旧教师是当前已解码 P_old 在旧组重新分配、local=0 时的 keep prior；不使用已淘汰 source 的完整策略或历史 behavior_probs 代替。

新观测为两个当前 resident owner 各最新 128 行，旧观测为现存旧组 FIFO 最新 128 行；各自时间顺序前 96 训练、后 32 诊断。不足行数、顺序/代次/绑定不可核验属于输入不符合合同，整批停止，不删 seed 或补历史日志。holdout 不选候选、超参数、初始化或 fallback。

实现冻结前必须把以下细节写成可核验接口，而非留给实验方解释：

- 独立记录每次 closure 的完整目标、新/旧 KL、候选接受/拒绝与终止原因；以明确的初始化候选建立 incumbent，闭包次数不能超过 256。记录 float32 回退，不能声称精确求解了受约束优化。
- B/C 共享一次 lambda=0 拟合结果；C/D 的差异只来自加入旧项及其拟合结果。C/D 的数据身份、初始化、正则、上限、安装、编码和容量合同相同。
- 给出从 prepared inputs 到补偿、原 codec、解码父矩阵、fresh local=0 的精确调用或科学评价接口。冻结旧/新教师后再安装；使用原完整 actor 编码路径，不能单独量化 parent 代替真实安装。
- 编码前核对 resident 有效矩阵补偿；编码后分别报告 fresh-slot prior KL 与 resident 全策略漂移。两者不能混作同一个保护指标。
- 清晰区分 A 的不重新编码 keep、B 的 new binding、C/D 的 wildcard。未来 D−C 是旧项的受控方法比较，C−B 是扩大绑定及其必要安装处理的效果，D−A 是整个保存动作的净效果。优化轨迹与量化变化属于各方法的真实后果，不能把比较解释为脱离实现的纯 KL 因果效应。
- 报告实际 actor 与完整 learner 持久字节；临时 teacher/优化工作区计入峰值内存，不能存入部署状态。硬上限一致不等于已经测得文件字节完全相同。

闭包接收顺序固定为：先把 C0 及其完整 L_lambda 设为当前最优；每个候选先检查有限性与新训练 KL 过滤，再按本臂完整 L_lambda 更新最优（相等允许后点替换）；预算耗尽返回已见最优。转 float32 后只按原新训练 KL 门槛检查、必要时回到 C0，不再以 holdout 或新增完整目标门槛重新挑选。float64/float32 的完整目标均记录。初始与最终度量调用单独计数，不能用“不是 closure”隐藏计算成本；lambda=0 对原 fitter 的合成一致性必须通过。

算法方须交付 `encode_and_score_stage0(prepared, fit_result, binding)` 或同等明确的科学接口，归属新输入/评价模块，而非让实验 runner 自行发明。固定顺序为：在 prefix 的工作副本中补偿并安装候选 → 调用原完整 actor codec 得到真实序列化 bytes → 从这些 bytes 解码实际父矩阵 → 在仅用于评价的副本中清零 local → 使用冻结旧/新教师和规定 holdout 计算 KL；另评价编码后的 resident 漂移及完整包字节。接口不更新 PPO、不调用环境、不读取未来奖励、不修改原 prefix 或 prepared 的教师。其确切 codec 调用、解码函数和参数随 METHOD_V1 冻结。

## E163 Stage 0 的固定筛查

固定复用 E161 的 16 个 prefix：26201–26213、26215、26216、26218。不读取其未来 reward/outcome 作为算法或筛查输入；不选择有利 prefix。每 prefix 拟合 lambda=0 与 lambda=1 各一次，共 32 次拟合，不先做真实试跑挑参数。

令 K_old,a / K_new,a 为实际安装并解码后、fresh local=0 的旧/新 holdout forward KL；新 KL 对两 owner 等权。令 G_new,a=K_new,W0−K_new,a。一个 prefix 通过，当且仅当四项同时成立：

1. K_old,C > 1e-10。
2. G_new,C > 1e-10。
3. K_old,D <= 0.75 K_old,C。
4. G_new,D >= 0.5 G_new,C。

至少 **12/16** 通过才标记 **MECHANISM_SCREEN_PASSED_EXPLORATORY**，仅支持提出后续奖励筛查。其他完整、有效结果为 **NO_ADVANCEMENT**。近零或非正新收益计不通过；不改分母、不删除失败 prefix、不用 train KL/float32 编码前结果替代。非有限值、身份/正确性错误或未完成整批为 **INVALID / INCOMPLETE**，不能伪装成机制被否定，也不能免费重试。

K_new,W0 明确定义为同一新 holdout、相同 W0/source_basis 与 temperature/epsilon 下，local=0、无父（C=0）的学生相对相同新教师的 KL；不使用原 resident 策略作 W0。1e-10 只作为数值非零 guard，不是有实际量级的 KL 效应阈值。必须报告绝对 K/G 与绝对旧 KL 减少量；比例筛查通过不能据此宣称实用收益，仍需另行奖励验证。

合法预算耗尽返回或 float32 回到 C0 都是预设算法输出，可按相同编码后门槛评分，不删除或重跑。必须标明 returned_is_C0、fallback/termination 及实际优化工作；若通过依赖初值/回退，只能归于该完整方法流程，不能声称优化出的旧项梯度已经产生保护作用。输入/非有限/正确性异常不属于合法回退，整批停止。

保留全 16 个 prefix 的训练/holdout、编码前后 KL、候选/数据/actor 哈希、32 次拟合次数与回退、完整字节、resident 漂移和资源记录。无需添加未来奖励、bootstrap 或额外图以完成此机制筛查。
