# H036 下一轮设计：零新增新训练代价的有限受限搜索

日期：2026-10-24（Asia/Singapore）。状态：**DESIGN_FOR_COORDINATOR_REVIEW；只交设计，未实现、未运行、未分配新E或预算。**

**选定方案：复用已保存的新拟合C、无过滤U和原D，在C→U线段上执行同一种有界回溯搜索，只切换“新训练KL约束是否参与搜索停止条件”。两臂保持同一完整目标、C0界和最终float32复查。覆盖原全部16个prefix，零重新拟合，不恢复未保存轨迹，不增加容量或依赖。**

本轮检验一个有限的存在性问题：在现有九系数表示、既定教师与C0新训练界内，一个未被原搜索交付的更优候选能否由这些现存锚点构造出来？找到即提供可行见证；未找到只否定本候选族及有限搜索，不证明必须放松代价或增加容量。这不是完整九维约束优化，也不是生产保存器确认。

依据：[E163规格](METHOD_V1.md)、[E163主控分析](COORDINATOR_E163_SYNTHESIS_20261023.md)、[E164主控分析](COORDINATOR_E164_SYNTHESIS_20261023.md)、[E164算法分析](ALGORITHM_E164_ANALYSIS_20261023.md)。H036仍INCONCLUSIVE，E163/E164原结果及额度关闭状态不改。

## 1. 为什么先选这个方案

现存closure记录主要是标量和哈希，不是完整参数轨迹；不能把其中某个好看的标量点重新编码，或从哈希重建参数。E164已评价F/U端点，重复这些端点不会补足“是否有中间可行改进”的证据。

当前可精确取得全16条的C、D以及U的float32参数。因此先从C的新拟合端向U的旧保护折中端做有限受限搜索，比另跑全部九维优化更便宜；它能给出真实参数见证，而非推测。搜索中的约束影响是否继续缩步，故不只是最后发现越界再回退。两臂有相同候选方向、目标和上限，避免把换优化器归因于约束。

不选SLSQP：现有`requirements-lock.txt`没有SciPy，本轮不安装依赖或改环境。不加入投影梯度、额外初始化、多方向、lambda/slack扫描；这些均不是失败后的自动后备路线。

文献借鉴仅限问题表述：[GEM，§3、式(6)](https://arxiv.org/pdf/1706.08840)把不允许增长的损失写成不等式约束。本方案限制的是新教师训练KL，且只搜索有限线段，没有采用GEM的多任务梯度投影，也不继承其保证或实验结论。有限参数插值本身不主张为创新。

## 2. 基线、输入与代价边界

| 对象 | 本轮用途与边界 |
| --- | --- |
| C0 | `float64(float32(M))`，原新来源均值初始化；定义唯一新训练界及最终合法回退。不是keep，也不是优化C。 |
| C | E163原lambda=0的最终float32候选；既作线段起点，也作原性能参照。它不是经证明的新KL全局最优点。 |
| D | E163原lambda=1的最终float32候选，即E164的V；作历史方法参照及搜索未找到更低L点时的保底incumbent。 |
| U32 | E164中UR所对应的原始float32候选；5个恢复项取已保存UR字节，其余11项按已验收U/F身份引用原D字节。全16均使用float32端点，不能5项用U64、11项用D32而混淆精度。 |

C/D字节来源：`experiments/exp163/runs/run002/remote/run002/cases/s{seed}/{c,d}/candidate.f32`及各自`candidate.json`。五个U32来源：`experiments/exp164/runs/run001/remote/cases/s{seed}/probes/UR/candidate.f32`，绑定原`lock.json`、`trace_artifacts.json`和E164的全cohort引用链。只读准确白名单；实现冻结时逐项列SHA，缺失/不符则停止准入，**不增加恢复fit**。

固定seed为26201、26202、26203、26204、26205、26206、26207、26208、26209、26210、26211、26212、26213、26215、26216、26218。五项恢复集合不成为本轮筛选条件；原11项身份相同不能证明新插值搜索仍无变化，必须全16实际完成训练选点。

输入、教师及分割完全沿用v1：原三文件准确身份；新owner各128行，前96训练、后32留出；旧FIFO最新128行按96/32分割。旧教师是实际解码旧父、local=0的keep prior，新教师为冻结resident完整有效策略。只使用training-only view中的新192行、旧96行、权重、M/C0和参数锚点。不得读取未来日程/回报、observer、完整历史或淘汰source参数补证据。

本轮固定经济容忍量δ=0：`b = K_new^tr(C0)`，可行判据`K_new^tr(X) <= b + 1e-12`。`1e-12`仅为原数值容差。该界只保护owner均权的新训练KL，既不保证每个owner均不退步，也不保证相对优化C没有新行为代价。把界改为C会改变可行域，故本轮只用C评价收益，不用它重设预算。非零δ意味着允许新的拟合损失，需要独立科学理由，不能看到结果后调到通过。

## 3. 唯一目标、有限搜索及约束开关

保持原定义：

`K_new^tr = .5 * sum_owner mean_train KL(T_owner || p_X)`；
`K_old^tr = mean_old_train KL(T_old || p_X)`；
`R(X) = 1e-4 * mean((X-M)^2)`；
`L1(X) = K_new^tr(X) + K_old^tr(X) + R(X)`。

不改temperature=2、epsilon=.05的学生概率、归一化、ridge或lambda=1；不能用普通softmax交叉熵的凸性结论证明此处可行域或线段KL单调。

每个prefix将C、D、U32按原布局读为3×3 float32，再准确转为float64。仅用训练oracle计算C0、C、D的L分项；核对D满足原新训练界。D若不满足或既有身份/原训练值不一致，是技术/复用身份问题，停止，不修改界或删seed。

唯一试探序列为`alpha_j = 2^(-j), j=0,...,15`，
`X_j = C64 + alpha_j * (U32_as_float64 - C64)`。
先按上述顺序生成float64点，尚不编码。两臂的搜索保底均为D，目标参考均为本轮同一oracle计算的`L1(D)`；完整目标严格相等时保留D。

| 臂 | 搜索停止条件 | 未找到时 | 固定后处理 |
| --- | --- | --- | --- |
| S0：约束不参与搜索 | 第一个满足`L1(X_j) < L1(D)`的点即停止 | 返回D | 同下文float32复查 |
| S1：约束参与搜索 | 第一个同时满足`L1(X_j) < L1(D)`及`K_new^tr(X_j) <= b+1e-12`的点即停止；越界则继续缩步 | 返回D | 完全相同float32复查 |

两臂只相差上述可行条件；不改目标、方向、候选顺序、最大试探次数或后处理。S1不是在整个线段取全局最优，甚至不宣称取完整网格最小L；它是预先固定的第一可接受步规则。S0−原D含候选族/搜索程序变化；**S1−S0才识别本有限搜索中让约束参与停止条件的影响**。若S1仅等于原D、S0因回退变差，不算找到新的可行改进。

每臂至多16次试探，不无限缩步。可按prepared/目标版本/float64参数原字节缓存两臂重复oracle调用，记录实际计算、逻辑请求和cache hit；不能把同一max试探数称为实际算量相同。原始L、新旧KL、ridge、各条件、点哈希和停止index全部保存。不保存/评分全部点的holdout。

对所选float64点转float32，再用同一新训练KL界复查：通过则保留，失败则原样回C0。即使S1转前可行，转后失败也不继续缩步或改选另一个点。保底D按相同流程处理。记录转前、原始cast、最终候选的分项/身份及回退；不增加转后完整L择优或留出择优。非有限参数/概率/目标为技术错误，不能悄悄跳过或伪装成C0回退。

训练数值oracle复用冻结目标和KL定义；现有解析接口若连同梯度一并计算，其开销也计入，不能声称是免费forward。每prefix最多3个基准点、16个不同试探点、2个转后点，即最多21个实际完整训练oracle评估，全16上限336；相同字节去重只降低实耗。底层目标/梯度/KL helper调用另列真实计数。这里没有重新优化C/U/D，没有研究fit。

## 4. 锁定、部署与留出隔离

训练搜索函数不接收新/旧holdout观测、教师或得分；不能直接调用会在fit中计算holdout的旧高层fitter。C/U/D虽然来自已见实验，算法不得用它们的holdout值选择方向、alpha、约束或臂。人的设计已知历史结果，故本轮仍是探索性复用，不能称独立确认。

先完成全16的S0/S1训练选点、cast复查和字节别名，保存全cohort锁定清单及SHA，再运行任何新增holdout评分。两个臂都必须评分或以完整身份准确复用，不按训练成功或是否改变D挑选评分对象。

同一冻结评分链：wildcard父绑定；原补偿安装保持编码前resident有效策略；完整actor int8编码/解码；评价副本清local=0；原teacher下计算pre-codec/encoded的train/holdout KL、G_new及resident漂移。清理actor optimizer、保留critic等规则、actor89 B和完整持久包≤262144 B不变。临时端点、oracle cache和搜索记录不进入learner。

**部署后界另报：**对完整int8编码解码后的fresh新策略，报告相对原数值界b是否满足及违反量；同时报告相对同链编码C0的差值，明确两个参照。该结果不回写选点或触发新增回退。编码前训练可行不等于部署可行，更不等于留出/reward保证。

旧C/D评分只在输入、prepared/foundation、候选、binding、科学评分版本与原run身份都一致时引用；最终新字节相同才能别名复用。候选相同但评分语义或依赖不符不能复用。全锁后先对固定seed26201的D做一个评分锚点，核对原actor字节与冻结评分值；不符则停止。之后最多32个新臂评分包，含锚点的保守上限33；重复点按准确身份去重。

## 5. 主比较、见证与失败解释

配对单位是原16个prefix，不是alpha、评分包或缓存项。主表为S1−S0的候选/回退、训练L与新旧KL、编码后旧/新holdout差，以及两臂真实成本；另列S1−原D，防止把控制退化当作方法进步。C是固定性能参照，保留原E163新收益/旧保护比例的描述，但不重写E163的8/16，也不借用原12/16作为本轮自动推进线。

预定义数值性见证（阈值均只用于报告，不改变搜索）：最终交付的float32 S1满足原新训练界，且`L1(S1) < L1(D)-1e-8`、`K_old^tr(S1) < K_old^tr(D)-1e-8`，参数字节不同。逐项另报它是否也优于S0。这样排除仅有微小数值变化、仅改善新项或仅恢复原D的假进展。

| 观察 | 可以判断 | 不能判断/本轮动作 |
| --- | --- | --- |
| 至少一个见证优于D | 该prefix在原容量与零C0训练代价界内存在原D未交付的旧保护改进；直接削弱“该处必须放松代价或增容量” | 不证明全16稳健有效；继续完成固定评分后结案，不自动扩候选 |
| S1比S0好但不优于D | 受限缩步避免了本控制的拒绝/回退 | 不算原方法升级证据 |
| 有转前见证，但cast回退或编码后失败 | 区分有限搜索可行、float32交付与完整编码三层 | 不修改门槛/codec或自动重选 |
| 编码后旧/新holdout同时改善 | 当前固定留出上的局部共同改善样例 | 不是新seed确认、可用选择规则或reward收益 |
| 全部没有见证 | 此固定线段、试探分辨率及规则未找到所需改进 | 不证明九维无解、优化已充分、需要非零δ或容量不足；本轮停止 |

若留出只改善旧项、牺牲新项，应如实报告取舍；若训练改善未转移留出，应记录泛化失配，不按留出换alpha。本轮没有可证的阴性排他结论，因此不能承诺一次廉价验证就区分所有容量/预算解释。
