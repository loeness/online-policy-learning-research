# 文献驱动的在线策略学习 V2：待测算法与结构草案

日期：2026-11-10  
状态：**设计候选；未实现、未冻结、未验证**。本文不构成实验启动或资源授权。

## 1. 目标与结论

研究目标是在持续交互、可学习的策略和完整状态存储有限的条件下，使过往经验在淘汰和重访之后仍能带来净收益。候选方案将知识生命周期分成**工作中的在线更新、有限知识的提交、后续调用**三个动作，并明确它们各自的证据、成本和失败方式。

推荐先测试现有架构中的一个最小动作：**同组槽位淘汰前，用淘汰时刻的完整策略作为教师，将其行为压入已有 parent；检查已驻留策略与旧 parent prior 的变化，并在实际编码解码后决定提交还是回退。** 这是 H037 的具体设计草案，不是已确认有效的算法。目标 V2 的独立技能节点、版本依赖和独立 Use Gate 是更远的结构候选，不在第一轮一起实现或检验。

## 3. 已有算法：写入问题发生在哪里

近期受控保存流中有冻结的预训练策略 W0、两个 local 槽和一个共享 parent。每个 local 有三个 band 的 3×3 矩阵，共 27 个系数；parent 为广播到三个 band 的 3×3 矩阵，共 9 个系数。对当前离散动作策略，可将结构简写为

```text
z(s) = z_W0(s) + B [ A_slot,band(s) + 1{绑定 parent} C ] ψ(s)
π(a|s) = (1 − ε) softmax(z(s) / T)_a + ε / 4
```

其中 B、ψ 由现有冻结输出基和特征构成，T 和 ε 分别为实际配置中的策略温度及四动作均匀探索混合系数；教师、拟合和验收必须使用一致的实际策略分布，实际运算以源码为准。PPO 在线更新 local，任务切换和 LRU 分配会清除被淘汰 local 及其优化器状态。当前例程中，槽位分配／清零前没有完整的 victim 行为交接流程。现有 `BoundedGroupEvidence` 是有界组级历史：最多保留每组 256 条 PPO 行，包括观测和采样时行为概率。这些概率来自不同时刻的策略，**不能直接视为淘汰时刻 victim 的策略**；旧任务观测也可能已被后续记录挤出。

因此，若利用已有观测，必须在清零前使用当时 victim 的 W0、parent 和 local **重新计算教师分布**；只能声称在可用观测集上拟合，不能宣称完整状态空间被保留。缺必要历史观测时必须记录并跳过本次写入，而不是虚构或事后从环境补取数据。

## 4. 目标结构：工作状态、持久节点与两个决策

```text
                 当前观测 + 可因果获得的历史
                              │
                     情境识别 / unresolved
                              │
                    Use Gate：调用哪个版本？
                         │            │
                   W0 + local     W0 + node + local
                         └─────┬──────┘
                               │
                        环境交互与 PPO
                         │           │
                  工作 local      critic / optimizer
                         │
              淘汰或其他预先定义的提交边界
                         │
           Write Gate：候选拟合 → 编码后验收
                         │
             有限持久节点 / 版本 / 依赖 / 证据
```

目标结构允许持久节点是独立技能，也允许引用基础策略或其他节点；**结构父边**用于组织，**功能继承边**决定实际策略计算，二者不自动等同。节点需要版本身份，引用方明确绑定到哪一版本；更改、删除或重绑定必须处理依赖、回滚和实际编码成本。W0 是明确的对照和回退选项，独立技能不应被定义为永远只能是现有 9 系数 parent 的变体。

上图是长期目标，不表示已实现。首轮仅使用现有 W0、两个 local 和单一 parent，不新建技能节点、不更换 PPO、不训练新路由器。已知组标签只用于受控阶段；最终无标签部署要求识别与绑定均只能使用可因果获得的信息。

## 5. 首个待测算法：同组淘汰前行为交接

### 5.1 触发与信息边界

在 rollout/update 的安全边界，确定将被清除的槽位 v。只在 victim 和当前 parent 明确属于同一个组、v 绑定该 parent、证据及容量允许的情况下尝试。parent 属于其他组、绑定未知或 wildcard 语义不清时，本次不写 parent；执行原有淘汰路径并记录原因。

在清除前冻结 W0、parent C0、victim local A_v、仍驻留 local、绑定关系、generation 和必要优化器状态。在 t− 已保留的观测中，按预先固定的时间块或样本身份划分训练和操作验收集；不得使用 t 之后的奖励、未来任务安排、环境反事实或隐藏测试数据。独立种子及真实后续 reward 只用于实验评价，不参与此处拟合或门控。

需分别取得 victim 观测、旧组 prior 观测以及驻留槽观测，规定每类最低样本数和分离规则。现有组缓存不保证都能提供；缺失时拒绝提交，记录可用率。如修改缓存，应预先指定 producer、替换规则及完整预算，且所有对照同样计费。切勿将当前时间混合的 `behavior_probs` 冒充淘汰时刻教师。

### 5.2 教师与目标

对淘汰前观测计算并冻结：

- victim 教师 `π_v^T = π(W0, C0, A_v)`：其完整有效策略，目标是让未来 local 清零后仍保留部分行为。
- old-prior 教师 `π_o^T = π(W0, C0, 0)`：只代表当前旧 parent 的初始化 prior，不代表所有历史旧任务的完整策略。
- 对每个仍驻留槽，冻结其完整策略作编码后保护检查。

令 `π_C^0 = π(W0, C, 0)`，一个具体的候选目标为

```text
D_v(C) = mean_{s in S_v,train} KL[π_v^T(.|s) || π_C^0(.|s)]
D_o(C) = mean_{s in S_o,train} KL[π_o^T(.|s) || π_C^0(.|s)]
C* = argmin_C  D_v(C) + λ D_o(C) + κ ||C − C0||²_F / 9
```

候选初始化为 C0；`λ=1`、`κ=1e−4` 可作为需要在实现合同中预先固定的**草案**，并非已优化参数。计算使用现有离散动作完整分布和其真实数值约定；迭代次数、计算上限、停止规则、样本下限、失败处理和精度在运行前由算法实现责任方冻结。优化结果可行或训练 KL 下降本身都不意味着应提交。

此设计与 H036 的核心区别是：这里的教师是**正在被淘汰槽的完整有效策略**，目标发生在同组淘汰前，且不使用 wildcard 跨组覆盖；H036 使用两个新来源教师与旧 `local=0` prior，研究的是另一项共享写入代理。

### 5.3 补偿、实际编码与提交

对每个仍驻留且绑定同一 parent 的槽，令每个 band 的 `A'_r,b = A_r,b + C0 − C*`。在浮点编码前，`A'_r,b + C* = A_r,b + C0`；未绑定槽不应被改写。接着以真正的 actor codec 序列化并解码完整候选，不能以浮点补偿等式代替编码后的实际行为检查。

仅在操作验收集同时满足以下预注册条件时提交：

1. 相对不写入 `C0`，编码后的 victim 教师 KL 至少改善 `δ_v`。
2. 旧 prior 相对 C0 的 KL 不超过 `ε_old`；每个驻留槽在自身观测上的解码后策略偏移不超过 `ε_res`。
3. 绑定、generation、编码身份、容量、回滚状态以及运行时序不变量均成立。

`δ_v`、`ε_old`、`ε_res`、样本数和置信解释目前**未冻结**，必须先依据指标尺度与独立数据指定；不得看本次验收结果后调节。门控集是操作验收，不是独立泛化证明，KL 阈值也不保证真实 reward 或安全。任何缺失、超限或错误均原子性回退到 C0、原绑定及驻留槽状态，再按相同 LRU 规则正常清除 victim；不凭空保留额外 victim 状态。parent 替换不能跨越正在使用旧 log-prob 的 PPO rollout；若版本切换，应在合法边界完成并处理优化器、版本及序列化一致性。

如果每次都以最近 C0 作为锚，连续写入可能发生累积漂移。**第一轮仅检验限定的单次淘汰决策**，不能据此宣称长期稳定；长期流需要固定时期锚点或其他独立累计保护，并对其存储和更新成本单独计量。

### 5.4 明确不做什么

不增加第二个免费 parent、不把跨组 wildcard 当默认、不把 parent 上 KL 改善当成旧任务收益、不假定三 band 平均投影能够替代行为拟合、不用测试数据选择 λ 或接纳阈值。第一轮也不把任务识别、调用门控、树节点增长与 PPO 更新方式一并改掉。

## 6. 后续调用设计：可拒绝的 Use Gate

后续版本可在**新 local generation 初始化时**，选择 `W0 + local` 或绑定某个确切 parent 版本后使用 `W0 + parent + local`。没有足够的同情境、同版本、过去独立配对证据；证据过期、情境 unresolved 或超出覆盖范围时，默认不绑定 parent，local 仍可继续在线学习。

只有预先定义的收益增量下界达到最小有用收益，且相应风险指标和覆盖条件满足时，才可在后续新 generation 调用；parent 改版后原证据不得自动延用。具体收益阈值、置信构造、风险定义、试用次数与预算尚未冻结。若做随机配对试用，必须计入真实交互和完整状态成本；分配机制、重复检验及数据依赖应与统计方法一致。相似度或 KL 只能用于候选筛查和漂移诊断，不能代替实际相对收益。H033/E162 不支持将其现有三特征模型直接上线为 Use Gate。

不在已训练的 local 上无条件切换 parent：须在合法 generation 边界完成，或明确补偿、编码和检查。已知任务组的固定绑定可以作为单列的 oracle 对照，但不等于无标签部署。

## 7. 第一轮如何验证，如何判定

本节是研究设计，不是已冻结实验合同；不指定 E 编号、种子数量、资源授权或声称正在执行。

**问题：** 在同一受控已知组流中，淘汰前将 victim 行为压入现有同组 parent，是否能在固定完整预算下改善重访，而不会以旧 prior 或驻留表现退化抵消收益？

**最小比较：** A 为原 LRU 清零、保留 parent；B 为本文同组交接，门控失败则回退 A。两臂使用相同的起始 checkpoint、事件、任务流、绑定语义、critic、PPO、编码、交互上限和完整状态预算；独立种子是主要统计单位。必须处理 A/B 拟合计算差异：共同提供同样的证据和计费，报告额外拟合、编码、内存峰值和墙钟；如要把提交效果与拟合开销分开，可设成本匹配的不提交对照，但不得把额外计算默认为免费。需要事先确定可比情况下的主指标、最小有用差、配对估计、置信区间、停止与失败规则。

**首要行为结果建议**是预先定义的真实后续流 reward/step 差，或预先指定窗口的 victim 重访回报／重访曲线面积，二者须在冻结前选定一个主终点。次要结果包括重访前初始化表现与再学习速度、旧任务和新任务分层、驻留性能、KL、尝试/接受/缺证据/回退比例、编码漂移、额外 CPU 时间与完整字节。旧多与新多场景应按预先规定分层，不能事后只报告有利场景。未发生淘汰或无可用样本的情况也须按预设处理，避免只统计被接纳事件导致选择偏差。

若需要区分保护项贡献，在独立的后续受控比较中，以相同数据、拟合预算和安装路径对比 `λ=1` 与 `λ=0`，预先明确 old-prior 接纳条件是否共同保留；否则结果会同时混入目标和接纳规则变化。若进入结构主张的确认，再加入直接 shared PPO、同分解 grouped-flat 和等完整字节的独立缓存等强对照。树与 grouped-flat 的已有等价证据意味着不能把简单容器差异声称为结构收益。

支持条件应同时考虑统计不确定性、实际最小收益、旧/驻留退化与额外成本；KL 改善但 reward 无改善只能支持代理拟合，不支持有效知识保留。缺证据导致大多数事件不尝试、压缩容量不足、量化后回退频繁、收益仅限特定分布、或完整预算下强基线更优，均是需要明确报告的否定性结果。

必要的 PPO/critic 健康度在同样环境和代码下作为诊断记录，例如价值预测对固定回报目标的校准、entropy、clip fraction 和 actor 更新幅度；它们不是写入作用的证明。只有诊断及独立问题支持时，才另行比较 critic 或 GTR 等更新方式，不与首轮交接同时更改。

## 8. 存储、可复现与交付边界

预算应覆盖 foundation、actor、critic、optimizer、持久和工作节点、证据缓存、教师／锚点、版本与索引、路由统计、检查点与序列化开销；同时分别报告峰值暂存、CPU/GPU、额外交互和推理延迟。历史 E163 中的 89 B 是特定 actor 编码大小，262,144 B 是该轮完整 learner 上限，不是 V2 通用额度；新方案是否容得下必须实际测量。

本文只提出结构和方法，没有形成冻结实现。后续若用户决定推进：主控确定一个问题、指标、门槛与预算；算法实现责任方补齐样本规则、损失、codec、原子回滚、入口、版本和远端检查合同并冻结；消融实验责任方独立审查后在指定服务器编排执行并交付原始证据；主控与算法分别分析，完成该轮后停止。信息通过用户手动转达。本次未运行研究代码、测试、实验或 SSH。
