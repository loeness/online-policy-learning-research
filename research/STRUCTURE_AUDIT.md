# 分类结构与 Citation 完整复核

日期：2026-10-20。范围是现存研究档案的分类、来源及相互链接；没有新训练、环境交互、指标重算或远程访问。

## 结论与边界

首轮完成了旧产物的归属，但“严格完成”表述过宽：有些 H 仍偏向外部文档索引，H/E 回链与分析版本不完整，citation 也未统一映射。本轮修补后，H → E → 历史 run 来源 → analysis 版本 → 原始工件的导航以及 citation 归属已补齐。

这属于**结构分类完成、历史来源缺口显式保留**，不是“所有旧实验完整可复现”。无法从保存材料核实的执行 commit、argv、精确分析输入/排除、绘图执行版本继续为 MISSING / UNKNOWN；文件哈希和当前 HEAD 都不能补造历史执行身份。

## 本轮修补

- H019–H035 补为可独立恢复核心问题与判断条件的生命周期摘要。区分原判据与回溯操作化；未记录的提出者、阈值、预算和初始状态不补造。保留原协议与长推导。
- 总索引增加直接 E 链接及证据入口；每个 H 链到 E、run、analysis 和附录，每个 E 回链主 H 与相关 H。
- E004 明确为零交互的科学诊断；其原输入哈希覆盖 E003、E005、E009、E010 及共享摘要，关联 H001–H004。分析执行的历史包装保留，不当成新增训练。
- E095 的中断来源标为执行失败、完成 cohort 标为 COMPLETED；E097 失败 clone 标为 FAILED。E092 两个无法区分失败/人工停止的来源仍为 UNKNOWN。中断成本的已落盘计数保留为下界。
- 既有分析报告/审计按真实保存位置建立版本来源，E090/E091 的原报告和后续报告均可回溯。E131 成功诊断、E132 重跑一致性结果及对应源运行得到直接链接。版本序号是导航顺序，不冒称历史执行时间。
- citation 接入总索引和全部 H/E。[引用总索引](CITATIONS.md) 与 [机器映射](citations.json) 区分借用改编、背景提及、拟比较方法、软件和附件来源；补入原已提及但漏登 BibTeX 的 CPC。

## 仍然存在的历史缺口

- 当前结构化 run 字段中，2 份核实完整 launch SHA，7 份保存了有证据的历史 argv；其余仍可能有原生快照/哈希或日志线索，未核实不等于不存在，但不能据此宣布已满足完整执行身份要求。
- 许多分析版本没有精确的历史分析 commit/命令。关联 run 表不等于这些 run 全部被合池；输入/排除以原审计、原哈希清单和报告为准。默认脚本参数仅为来源线索，不能充当已执行 argv。
- 图与其相邻 analysis 文件的存在，不自动建立精确绘图血缘；没有绑定的源数据、绘图命令/版本仍是复现缺口。复核时的 SHA-256 仅标识保存工件。
- 9 份附件不补造作者、会议录用或 arXiv ID；已匹配的公开版与实际阅读附件也可能不同。除 CPC 补漏外，本轮没有逐篇重新外部核验全部书目。
- 没有可恢复的当前批准剩余算力/存储额度，不能把历史预估或已发生用量当作新实验授权。完整 C2/C3、动态结构和其他 PROPOSED 项仍未执行。
