- **记录类型：** 2026-10-20 retrospective import；不是新预注册。最初提出日期与提案人未在存档中记录。[docs/EXPERIMENT_INDEX.md](../../docs/EXPERIMENT_INDEX.md) 将这一轮 write-decision investigation 标为 2026-10-16。
- **原始登记状态：** 未找到；本记录仅为 2026-10-20 回溯分类。
- **当前状态：** INCONCLUSIVE（当前 gate 与 LRU 回收规则未呈现稳定优势；广义原假设尚未充分测试）。
- **实验：** E081–E091，见各 E README。

## 研究问题与原始假设

在有限共享参数和固定容量下，在线学习得到的局部更新能否通过收益证据 gate，安全地成为可复用的持久知识？当共享父模块占满时，累计 profile 与有界回收能否增加分组覆盖，同时保住在线回报？

历史机制先更新局部参数 A，再提议共享参数 C；joint trial、relaxed trial、projection、local promotion 或 rollback 决定 C 的持久变更。评分使用行为概率、advantage surrogate、ESS、KL 和有限旧槽证据。被拒绝的共享更新通过补偿留在当前局部 A。当前策略在编码前保持等价，不等于发生了跨任务收益。父模块回收只在两个父组满载且存在兼容 profile 时启用，并用 LRU 决定回收对象。

原预测是：合适的门控可在保留局部学习收益的同时胜过 reward-aware sharing；独立 counterfactual 能指出错误接受或错过的候选；累计 profile 与有限回收可增加覆盖，而不降低全流表现；完整交互预算下 gate 不应被更强的独立 learner 轻易超越。

## 迭代与证据

- **第一轮（日期未能从原始协议确认）：** 八个 validation 条件；首次实现因 generation 元数据冲突和 reward support 误判而失败。后续支持感知修订只比较双方有观测支持的 reward 特征；旧失败 cohort 未并入选择。
- **2026-10-16 附近的正式轮：** validation 选出的 trial_gate_relaxed 与 projected_gate 和三项简单基线比较。正式 reward_shared 平均在线训练回报为 0.019149，trial_gate_relaxed 为 0.018754；复杂 gate 没有超过 reward-aware sharing。单独的 trial_rollback control 在三个 seed 上比 relaxed gate 低，说明 controlled cohort 中可能存在共享增量效果，但它仍低于简单 reward-aware sharing。
- **counterfactual 补充：** 对 23 个候选执行 42,714 个付费 observer steps；出现一例接受但旧任务受损和一例拒绝但候选有益。样本只覆盖每条正式运行中抽取的少量决定，不能估计错误率或安全保证。
- **容量和底座压力：** 两个 detour foundation 的 gate 在原留出型独立对照下仅呈小幅描述性优势；增加同总交互数、把所有交互用于 PPO 的独立基线后，W0-17 与 W0-29 均由独立基线领先。两个底座分别报告，没有合池。
- **父模块实验：** no-recycle cumulative validation 的两个 seed 中，trial_gate_relaxed 相对 reward_shared 的平均全流差为 −0.0005；有界 recycle validation 的预设 paired gain 对 trial_gate_relaxed 和 reward_shared 分别为 −0.000651 与 −0.000748。正式/unknown 扩展按预设规则跳过。初版报告曾标记 audit 失败；后续 write_current_reports/index.json 与当前派生报告对同一 cohort 报告 audit 通过，两个报告版本均保留。

## 事实、解释与边界

**观察事实：** 首次 validation 有 16 个尝试单元、9 个完成单元，原始训练/探测/评估成本为 267,264 / 22,016 / 103,391 steps。支持感知 validation 完成 485,042 次交互；formal 完成 759,378；rollback control 完成 152,067。counterfactual、detour、预算对照、累计 profile 和回收均有独立 E 记录，包含失败与 audit 修订。

**当前解释：** 控制试验显示共享更新可能比保留全局 joint trial 增量更有用；但 gate 尚未优于简单 reward-aware sharing，真实单次收益与风险的 false-accept / false-reject 仍证据不足。父模块 recycle 的小样本 validation 为负，不能据此证明 LRU 在所有环境都无效。

**不支持的结论：** 这些小型导航任务与少量 seeds 不支持策略安全、最优父模块组织、C2/C3、普遍持续学习或 SOTA 主张。accepted/rejected、组覆盖率和 score 下界均不是收益真值。
