# H013：分组支持、局部歧义与奖励冲突

**规范状态： INCONCLUSIVE** — 证据混合且不足以解决完整主张。

**记录性质：** 2026-10-20 回顾性导入，不是新的预注册。历史诊断与阶段材料日期为 2026-10-16；原提议者及协议作者未记录。

## 原始问题与可检验主张

H011 的转移相似性是否足以识别可共享的情境？有限证据会不会隐藏局部情境差异；即使动力学相同，奖励目标相反时共享更新是否会产生负迁移？原 S3 协议将其作为保持正、负结果的诊断问题，不预设共享一定失败。可观察预测包括：低支持时 grouper 应允许未决；同分参照应拒绝强行分类；若奖励未参与 profile，而两情境仅奖励符号相反，共享更新可能恶化未训练目标的回报。

机制分成两部分：离线重放同一批已保存 probe，在改变 prefix 长度或屏蔽动作后测 group assignment、覆盖和 abstention；另在相同动作动力学、观测与终止条件下反转奖励，用真实 PPO 更新测共享写入的冷迁移。两项证据不可互相替代。历史材料没有标注具体外部方法来源。

## 生命周期与轮次

- **2026-10-16，支持与歧义诊断：** 从 H011 的正式 probe 读取既有 9,216 行，不运行环境；建立 [E067](../../experiments/exp067/README.md)。
- **2026-10-16，S3 奖励冲突：** 同动力学、反号奖励下执行一个 pilot 和三种子 formal，分别为 [E068](../../experiments/exp068/README.md) 与 [E069](../../experiments/exp069/README.md)。
- **2026-10-20，回顾性整理：** 规范状态为 INCONCLUSIVE；局部证据混合：歧义拒绝行为获组件层支持，奖励冲突例子显示负迁移；未建立普遍安全规则或灾难性遗忘结论。

## 配置、事实与解释

- **E067，离线诊断：** 复用 seeds 677、691、709 的 probe，按 16/32/64/128/256/512 行前缀重建 profile；并对动作 0/1 证据做 censoring，另手工构造三组同分参照。环境新增交互为 0。观察到平均分配覆盖率从 16/32 行时 27.8%，到 64 行 50.0%、128 行 88.9%、256/512 行 100%；低覆盖时已解析 pairs 零错误的分母很小。动作 0/1 censoring 后家族 pairwise accuracy 为 100%，但 A0/A1/A2 均与三个 A full reference 兼容，差异藏于未试动作 2/3；三组显式平局都返回 `-1 / ambiguous_match`。这些是保存流上的离线审计，不是策略收益或普遍识别性证据。
- **E068/E069，奖励冲突：** 两个 route 共享同一 A0 动力学、观测、动作移动及 episode 终止；负 route 使用相反符号奖励，profile 不包含奖励。pilot E068 使用 seed 853、24,543 次交互，未观察到负目标冷迁移下降。formal E069 为 seeds 773/787/797、9 个 seed-condition 输出单元（3 seeds × 3 arms），由一个 cohort-level producer invocation 生成；训练 147,456 步、probe 9,216 步、评估 51,176 步、207,848 次交互。共享正目标参数使未训练负目标 cold return 平均变化 −0.5477（逐种子 −0.6375、−0.41875、−0.586875），独立局部为 0；formal 120/120 项审计通过。
- **旧目标与限制：** 之后训练负目标时，active 的正目标回报变化均值 −0.0444，逐种子 −0.0244、−0.1163、+0.0075；独立和冻结保持不变。未显示严重崩溃，但正目标自身学得不充分，不能声称稳健或已证明灾难性遗忘。
- **解释：** 动力学 profile 可支持某些分组，但不识别所有局部任务，也不提供 reward compatibility 或 policy-benefit 证据。该反例支持把“环境/动力学兼容”与“这次共享参数更新对目标策略有益”分开判断。它不能推出任何更完整算法都会失败。
- **预算与数据：** conflict 使用浮点 actor cap 1,024 B、W0+单个 checkpoint cap 256 KiB。历史获批计算/时间预算未找到记录。support diagnostic 的原始输入路径是三个 formal `independent/probe_steps.csv`；本次整理未读取这些原始轨迹。
