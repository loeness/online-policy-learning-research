# H015 — 已知与未知边界下的在线写入流

- **记录类型：** 2026-10-20 retrospective import；不是新预注册。原始提案人和首次提出日期未找到；[docs/EXPERIMENT_INDEX.md](../../docs/EXPERIMENT_INDEX.md) 将 write stream cohort 标在 2026-10-16。
- **原始登记状态：** 未找到；本记录仅为 2026-10-20 回溯分类。
- **当前状态：** INCONCLUSIVE（所测 full-use 对照削弱当前共享 gate 的表现主张，但不否定更广泛的在线共享写入问题）。
- **实验：** E092–E098。

## 研究问题与假设

在连续任务流中，已知本地索引与未知边界路由分别怎样影响在线更新、共享参数、有限缓存和恢复？原假设是，在线共享写入能在有限 actor/package 容量下帮助后续任务复用，并且在完整交互预算下不逊于独立学习；未知边界路由可以用可见 transition/reward 证据工作，而不接收 task name、family、preference 或切换通知。

方法使用冻结 W0、int8 actor、最多两个 reward-aware shared groups 和有限 local slots。Known harness 使用已知本地索引并在首次分配时付费 probe；unknown harness 每步由 router 处理可见状态，并对 unknown route 使用 base/uniform 混合。独立 7 槽基线使用每个在线 interaction 做 PPO fit，作为 probe-inclusive 的完整交互预算对照。

## 预测与削弱证据

预计 gate/shared 方法在 12 个任务的持续流和自然复现中，比 independent cache 更有效；如果预算控制在 known/unknown 两种边界条件都领先，则会支持该方法的在线价值。若完整数据利用的 independent7_lru 在匹配 training+probe interaction 数后持续领先，则会削弱这一主张。

## 事实与结果

- **Known pilot：** v1 在环境交互前失败；v2/v3 分别保留 168 与 3,880 个原始交互；v4 完成 28,317。四次实际调用分别保留，不能将早期失败删除。
- **Known main：** 3 seeds × 7 conditions，共 21 runs，含 1,032,192 training、47,744 probe、56,345 evaluation steps，总计 1,136,281。在线全流指标：trial_gate_relaxed 0.006329、reward_shared 0.006081；同交互预算 full-use independent7_lru 0.007487。
- **Unknown pilot：** 1 seed 完成 25,987 次交互。
- **Unknown main：** 3 seeds × 4 conditions，完整 cohort 622,487 次交互。先前外部中断 cohort 另保留 36,442 个 training steps；resume 仅用于完成缺失单元。结果摘要曾缺少协议字段，后从 verified frozen config 补齐，修复前报告及原 summary 都保留。全流指标 trial_gate_relaxed 0.005722、reward_shared 0.005546；full-use independent7_lru 0.008187。Unknown gate 正任务成功率约 13.2%，基线约 21.6%；终点成功率约 18.1% 与 26.4%。
- **Known full-use baseline：** 3072 training-step 的单 seed pilot；已知控制正式 cohort 有 154,368 training + 8,045 evaluation steps。初始 endpoint-clone 失败另计 154,368 training steps，失败原因与 deepcopy 的非叶 autograd tensor 有关。
- **Unknown full-use baseline：** 147,456 training + 8,068 evaluation steps，总计 155,524。

## 当前解释与限制

完整交互预算下，独立 full-use 控制在 known 和 unknown 的平均在线回报都领先所选 gate；known/unknown stream 的 3 个部署 seed 只支持描述性结论。总 interaction 匹配不等于相同 PPO 更新数、compute 或每个 task 的 policy dwell time。Unknown route/eviction 是观测日志，没有独立 truth labels，不能据此计算误路由率。这个结果削弱当前方案，不否定在线学习或有限共享知识的研究问题。
