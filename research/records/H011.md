# H011：用在线探测证据进行共享家族分组

**规范状态： TESTED** — 已检验；证据只支持给定 route 与生成器下的局部分组信号，不是未知情境发现或广泛 SUPPORTED。

**记录性质：** 2026-10-20 回顾性导入，不是新的预注册。历史材料将该阶段列于 2026-10-16；原提议者及协议作者未记录。

## 原始问题与假设

在 route slot 与切换时刻已知、但家族标签不提供给 learner 时，短程真实转移探测能否替代人工给定的家族标签，为共享参数分配情境？S1b 协议以数值转移 profile 分组，并允许支持不足、模糊或容量已满时保留局部修正。预测是 profile 分组可在该固定生成器中复原家族关系并保留持续共享带来的留出冷迁移；若和 oracle 分组不一致或没有策略作用，假设会被削弱。

机制是统计各区域、动作和实际移动方向，在有阈值的两个组之间匹配。family、context name 和 route slot 不输入 grouper；但 route、边界、特征结构、动作输出坐标及最大组数仍由实验者给定。没有记录明确借用的外部算法或文献。

## 生命周期与轮次

- **2026-10-16，S1b：** 基于 H010 的共享写入机制，加入无家族标签的 probe-based 分组；pilot 和 formal 分开记录为 [E063](../../experiments/exp063/README.md) 与 [E064](../../experiments/exp064/README.md)。
- **2026-10-16，历史解释：** 三个正式种子在本生成器中恢复两组并复现 oracle 结果。历史 pilot 在训练完毕后的汇总后处理失败，随后从既有产物修复，未新增环境交互。
- **2026-10-20，回顾性整理：** 规范状态为 TESTED；解释仍是给定路由场景下的初步局部信号，不代表未知情境或通用家族发现。

## 配置、事实与解释

- 六个已知路线，每个情境第一次出现时均匀随机动作探测 512 步；探测只计数可见状态、动作和下一状态中的移动方向，不用奖励、名称或家族。每个情境只分配一次，未测试后续换组。正式条件为独立、oracle-active、auto-active、auto-frozen；三个种子 677、691、709。主指标为分组一致性与 A2/B2 留出冷启动回报，方向越高越好，同时报告在线成功率和完整交互成本。
- 浮点 actor cap 1,024 B，W0 加单个 checkpoint cap 256 KiB。历史获批计算/时间预算未找到记录。
- **观察事实：** pilot E063 为一个种子，85,783 次交互；正式 E064 有 12 个 seed-condition 输出单元（3 seeds × 4 arms），由一个 cohort-level producer invocation 生成；共 491,520 训练步、36,864 probe 步、110,611 评估步、638,995 次交互。正式三种子将六个 context 全部归到与 oracle 家族一致的两组，auto-active 与 oracle-active 策略结果相同。在线成功率为 auto-active/oracle 42.57%、独立 29.99%、auto-frozen 35.14%。seed 677 的留出成功率下降，不能声称每次共享更新改善策略。正式审计 51 项通过。
- **失败与修复：** pilot 的 preboot 汇总因比较不同 condition 名称而报错，`POSTPROCESSING_FAILURE.json` 记录训练输出未变；修复后以既有输出生成汇总，额外交互为 0。它是后处理失败，不是重新训练。
- **解释：** 512 步探测能在这六个有利、已知路线的上下文中替代家族标签，并使共享写入产生类似 oracle 的结果。探测成本已支付；不是零经验迁移。分组正确也不能证明共享参数有益，或识别未知边界。
- **未解决：** 有限/未知支持下的局部身份歧义、安全共享判断、自动 route 与 slot 发现，以及跨 W0/环境泛化。
