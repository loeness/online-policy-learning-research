# H020 · 候选来源剂量与保存内容效应

- 当前科学状态：INCONCLUSIVE（保留原状态）。

- 原始证据来源：[冻结协议](../../docs/SOURCE_DOSE_PROTOCOL.md) 与 [结果审查](../../docs/SOURCE_FOLLOWUP_REVIEW.md)。

## 原始问题、主张与机制

前一轮旧候选的两个来源各训练 2,048 步，而新候选来源各训练 1,024 步。本轮的原始问题是：固定同一个共同前缀和 learner，只改变旧候选内容（来源各拟合 1,024 或 2,048 步）后，完整保存行动的后续价值是否改变？这检验来源剂量对候选内容的影响，不等于匹配候选质量，也不代表自然部署中全程缩短来源训练。

## 原始可观测预测与判别规则

主要估计 B = 平均[(replace − keep)1024 − (replace − keep)2048]，按关系报告。预设正向支持条件：均值至少 +0.002 reward/step、至少 6 / 8 个 seed 为正、描述性 95% 区间下端大于 0。若区间上端低于 +0.002，则不支持该实际量级；其余为不确定。三重交互 Q 双侧报告，不把观察结果改写为预测。频率规则须超过 keep、replace；若主张优于简单整合还须超过 mean。

## 轮次配置、比较与预算

- 环境 / 数据：同一 W0、dynamics 与 reward_conflict 关系、两种历史和未来。8 个新 seed、32 个共同前缀。候选旧内容取自每个 old source 的 1,024 或 2,048 步时点；低剂量内容不参与实际前缀行为，仅在干预时安装。
- 主要对照：每个旧候选剂量下，对同一前缀分叉 keep、replace、mean、none；past-only frequency / recency / gain / lower 在未来展开前冻结。完整未来每分支 12,288 步 PPO；替换或 none 仅在完整状态 hash 一致时复用物理分支，不能将 alias 计为新样本。
- 主要指标：未来累计奖励 / 步及 B；方向越正越支持低剂量旧候选提高 replace 相对 keep 的价值。0.002 reward/step 为预设实际量级。
- actor 容器 89 B、完整包上限 262,144 B。计划主 cohort 5,111,808 步，实际主 cohort 同为 5,111,808；pilot v1 和 v2 各 39,936 步，因此可核实的本轮合计 5,191,680 步。历史批准上限与剩余预算：UNKNOWN，不从预计或实际成本反推授权。

## 当前边界与下一决策

观察到来源剂量对保存后果有小幅条件效应，但预设实际量级与独立自动选择增量未建立。相同步数不能推出同质量候选。保留这个负的普遍化结果，并按 H026 的有界观测候选构造继续判断；不自动追加剂量矩阵。任何历史 GPU / CPU 时间缺失为 UNKNOWN。
