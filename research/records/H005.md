# H005：固定布局下的 C1 共享策略机制

- **状态：TESTED（固定结构先验下的共享分解在所测任务中表现强；不支持树拓扑独特优势）。**
- **日期与来源：**`c1_protocol.md` 和 `phase_c_plan.md`，2026-10-14；提出者未记录。2026-10-20 回顾导入。
- **研究问题与原假设：**真实奖励驱动的在线 PPO 能否从已见局部变体学到共享父级修正，使留出同族变体冷启动/适应优于 flat independent residual 与共享字典？固定 family、树、x-band gate 是先验，协议没有把它称作自动结构发现。未记录事后数值预测。
- **机制与关联：**固定 A/B 两族，各有三种区域动作响应；tree parent 来自在线 reward 学习，leaf 加局部残差，flat 与 dictionary 是对照。知识发现、强模型基线、等价 grouped representation 和 compact basis 见 [H006](H006.md)。
- **配置：**W0 单一 foundation；验证 seed 901，正式 deployment seeds 71/83/97；低/高容量 tiers，见 [configs/c1.json](../../configs/c1.json)。主要指标为 A2/B2 冷迁移、六任务最终表现、旧任务保留及恢复，另报告 serialized state、rollout、workspace 和 RSS。总 wall/compute 预算未记录；容量上限不是实验时间预算。

## 结论边界与下一判断

**事实：**固定树在本轮达到较高成功率，但可加父/叶机制可由等价 flat grouped 表示；known-map 检查显示任务和结构先验匹配。**解释：**证据支持受控结构下共享分解可行，不证明在线经验会自主发现层级、树优于所有合适表示、容量满后能整合，或一般环境能迁移。**未决：**oracle ID 用于 seen/heldout/revisit，隐藏 history 使用已标注 calibration bank；history 的 post-policy eval 又是 oracle route。下一决策由研究者判断是否沿原核心问题继续；此记录不授权 C2/C3 运行。
