## 原始问题、主张与机制

这项工作确认而非创造一个新规则：在先前出现 lower 局部信号的导航 dynamics、old 来源各拟合 2,048 步、new 来源各 1,024 步、history = future 条件中，冻结的 surrogate_lower 能否优于始终 keep。lower 只在过去证据上评分并选择一次操作；未选行动结果仅是付费 observer 对照，不可当成部署时反馈。

## 原始可观测预测与判别规则

主估计为 16 个未见 seed 的 R(lower) − R(keep)，先在 seed 内平均两种历史，再做家族 A/B 分层 seed-cluster bootstrap。均值 > 0 且区间下端 > 0 支持局部正方向；区间上端 ≤ 0 不支持；其余记不确定。+0.002 reward/step 是单列实际量级参考；达到方向判断不等于达到此量级或算法创新。主要规则、条件及参数不随本轮结果调整。

## 轮次配置、比较与预算

- 环境 / 数据：固定 W0、已知 task / group / boundary 的导航 dynamics 关系；16 个新部署 seed，两个历史共 32 前缀；每 case 只跑与历史同名未来。两 old source 各 2,048 步，new source 各 1,024 步。
- 比较：keep / replace / mean / none 四个付费完整 PPO 分支；lower 和 frequency 等 past-only 决策按真实选中分支计值，未选分支为 observer。每个分支 12,288 步、rollout 256。主比较 lower−keep，次要对照按冻结规程列示。
- actor 容器 89 B、完整包上限 262,144 B。预期且主 cohort 实际 1,966,080 步，独立 pilot 15,360 步。授权预算上限 / 剩余额度：UNKNOWN；小内存限制仅用于调度，不能读作速度结论。
- 执行快照与工件由 [E119](../../experiments/exp119/README.md)、[E120](../../experiments/exp120/README.md)、配置与 run provenance 链接；本 H 不重复声称未核实的 SHA。

## 当前边界与下一决策

保留原 lower 规则的负确认，不从 observer 分支或一个探索性局部格子重新定阈值。观察者为估分而付费运行未选分支，不代表部署算法可免费取得反事实。H023 / H024 后续检验了不同问题：所选反馈预测及其全流策略增量。当前无本记录授权的复跑。
