# H021 · 持久保存与未来继续学习的交互

- 当前科学状态：INCONCLUSIVE（保留原状态）。
- 原始协议日期：2026-10-18；本生命周期摘要于 2026-10-20 回溯补入。
- 提出者：UNKNOWN；原始 H 独立登记日期、初始 PROPOSED 状态及逐次状态历史：UNKNOWN。不得把本次回溯摘要称为预注册。
- 原始证据来源：[冻结规程](../../docs/LEARNING_INTERACTION_PROTOCOL.md) 与 [合并审查](../../docs/SOURCE_FOLLOWUP_REVIEW.md)。

## 原始问题、主张与机制

将持久巩固与暂态携带操作化为 replace 与 none：两者在编码前补偿当前驻留局部策略，后续自然淘汰时 replace 可继承共享候选，none 不保留共享内容。原问题是：保存带来的后续回报差是否会因继续做 PPO 梯度更新而不同于只经历真实交互、LRU 与继承的无梯度延续？研究目标是识别额外交互，不把一般回报增长归因于新知识组织算法。

## 原始可观测预测与判别规则

定义 S_train = R(replace, train) − R(none, train)，S_frozen = R(replace, no-gradient) − R(none, no-gradient)，T = S_train − S_frozen，单位 reward/step。原协议未规定 T 必须为正才算 idea 成立；正值表示当前设置下正交互，负值表示 PPO 缩小保存差距，接近零表示可加或未辨明。实际量级按 ±0.002 分别报告；只有描述区间完全超过 +0.002 或低于 −0.002 才称有明确实际量级交互。等效性判据：UNKNOWN；不得把跨零写成证明无协同。

## 轮次配置、比较与预算

- 环境 / 数据：H020 source-dose cohort 的同一 W0、32 个共同前缀，dynamics / reward_conflict 两关系、两历史和两未来；无梯度分支使用与有梯度 PPO 分支相同日程和 reset 机制。
- 对照：32 × replace / none × 两未来的 128 条无梯度真实续程，另与已有有梯度分支按共同前缀比较。无梯度不是固定策略：仍执行动作、奖励、LRU 和先验继承；actor / critic 参数梯度与 optimizer step 禁用。
- 主要指标：T 的 seed-cluster 描述性区间，按关系及主条件 history = future 报告；另报前 256 / 512 步和每 bout 曲线。完整续程 12,288 步；基线不是外部 PPO / SOTA。
- 新增主续程 1,572,864 步；独立 pilot 新增 12,288 步。共同前缀、有梯度分支来自 H020，不重复计费；可核实本 H 新增环境交互 1,585,152 步，另有零交互启动失败保留。原批准上限 / 剩余额度：UNKNOWN。
- 完整包沿用 262,144 B 上限和 89 B actor 容器；代码与运行证据链接在 [E116](../../experiments/exp116/README.md)、[E117](../../experiments/exp117/README.md) 和下列协议 / runner。各 run 的 exact code provenance 以 linked provenance 为准。

## 当前边界与下一决策

当前证据不支持“持久保存会额外放大本设置下未来 PPO 收益”的强猜想；它不否定 PPO、持久知识或其他组织方法的价值，也未通过等效性检验。无梯度下 replace 与 none 已可出现回报差，但两者间差值没有被继续 PPO 明确放大。下一步优先处理候选内容与条件效应，不重复同一交互矩阵。
