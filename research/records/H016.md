# H016 — 删除在线局部参数后，公共修正是否保留知识

- **记录类型：** 2026-10-20 retrospective import；不是新预注册。源协议没有确认原始提案日期或提案人；Stage 1 的回顾文档给出本轮原始设计。
- **原始登记状态：** 未找到；本记录仅为 2026-10-20 回溯分类。
- **当前状态：** INCONCLUSIVE（有限兼容任务上有探索性正向信号，未确认广义整合）。
- **实验：** E099–E100。

## 问题与原始假设

把多个已学习局部修正提取成一个 3×3 公共参数 C，再删除所有源局部/critic/optimizer/history 后，冻结策略能否在有限 actor/package 容量下保留或迁移控制能力？原预测：简单平均或 evidence-weighted 候选优于仅 W0；相关未训练变体可能受益；不同控制家族或相反 reward 目标会暴露错误复用损失。该机制是固定路由 observer 诊断，不是部署算法。

方法比较 local-only、两来源三 band 系数 mean、有限锚点激活加权 ridge、与加权候选同范数 random。创建全新 W0 learner，只转移候选 C；所有在线局部状态清空，目标策略冻结，无 PPO/探测/记忆更新；对比使用同初态与动作随机数配对的短 episode。

## 事实与解释

正式 exploratory cohort 使用旧 seeds 1009/1013/1019 的源 checkpoint，源任务 A0+、A1+ 各训练 8192 步；目标为 A0+、A2+、B2+、A0-。simple mean 相对删除后的 W0，在 A0+ signed return 平均 +0.480，在 A2+ +0.557；A2+ 的 seed 方向并不一致。对 B2+ 和相反 reward 的 A0- 平均分别为 −0.887、−0.883。weighted 在 A0+ 与 A2+ 每个 seed 均低于 simple mean。

这支持一个窄观察：某些相容源知识可在局部状态删除后以固定路由参数产生收益；它没有证明所有源策略可压缩，也没有估计自动路由器或完整源策略能力保留比例。B2+ / A0- 目标被强制分配来源 parent，不能当成部署时误路由率。A2+ 是探索结果，不是独立确认。

## 配置与成本

- **环境与指标：** C1 navigation；primary 为每来源 seed × target × arm 的 signed episode return，越高越好；8 episodes/target/arm/source，最多 64 steps。
- **配置/协议：** [configs/consolidation_retention_stage1.json](../../configs/consolidation_retention_stage1.json)、[docs/CONSOLIDATION_RETENTION_STAGE1_PROTOCOL.md](../../docs/CONSOLIDATION_RETENTION_STAGE1_PROTOCOL.md)。
- **数据：** source checkpoint 来自 [outputs/write_decision_causal_control](../../outputs/write_decision_causal_control) 的 trial_rollback 条件；数据路径明确到 cohort/seed/condition。stage1 的 source manifest 未绑定 Git commit。
- **预算：** 历史批准 compute 未记录。E099 pilot 新执行 974 次 observer interactions；E100 main 新执行 22,746 次 observer interactions、0 训练步。main 另复用源训练 98,304 步，不重复计为新成本；历史 source checkpoint 包含 110,207 次相关训练/探测/评估交互（按回顾文档定义）。
- **容量：** actor 容器 230 B；W0 + checkpoint + sidecar 合计实际修正后 113,900 B，低于 256 KiB。pilot CPU/wall 1.66/1.94 s；main 10.50/10.89 s。

## 借用方法、限制与下一决定

协议未声明对外部论文算法的借用。该实验只验证冻结策略下候选内容是否起作用，不评估在线自动提取或 storage optimality。后续自然淘汰闭环在 H017/E101–E103 独立运行，不能与本 E 合并成同一指标。

下一步只保留 simple mean 作为强探索基线；若要验证可部署整合，需新 seed、真实在线淘汰、同预算 independent capacity 对照，并把模型源与提取机制分开。这里不授权新实验。
