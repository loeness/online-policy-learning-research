## 原始问题、主张与机制

H023 的预测误差改善能否转化为完整重复写入流中的策略收益？冻结比较有界 selected-feedback learned_linear 与 learned_intercept、简单操作规则及直接共享 PPO / 独立 local 学习。每次仅将实际被选的动作结果回馈给 bounded selector；这同时检验预测、选择、自然淘汰和复现的完整策略，不把 H023 的 MSE 信号直接当作效用增益。

## 原始可观测预测与判别规则

预设主要比较为 learned_linear − learned_intercept 的完整流 reward / step，dynamics 与 reward_conflict 分开；+0.002 reward / step 单独作为实际量级参考。预设比较还有每一方法相对 keep、replace、mean、frequency、generalized lower、直接 shared PPO 和 independent 的结果，但未规定多方法中一个单一通用成功阈值：UNKNOWN。结果若仅预测 MSE 变好，不支持策略收益；selector advantage 还须超过固定启发式与强控制，不能凭相对 independent 的改善确立贡献。

## 轮次配置、比较与预算

- 环境 / 数据：固定 W0、两 local 槽及一共享 parent，dynamics / reward_conflict 两关系、自然 LRU、连续 episode。calibration 使用 6 个 seed / 12 流；策略 comparison 使用 4 个新 seed、80 流、每流 48 决策、10 方法。各阶段 seed 不重叠。
- selector：四 action-specific discounted ridge 模型（linear 六特征；intercept bias），ridge 1 / discount 0.97；前 16 决策均匀探索，再 epsilon 0.1 greedy。目标使用 block reward / step 减 measured decision-and-block CPU / step；更新只用所选结果。其他方法含 random、keep、replace、mean、frequency、lower、shared PPO、independent。
- 主要结果指标：含 warmup 的整条在线流 reward / step，越高越好；CPU、实际包大小、更新量、首 256 步复现另报。模型训练目标包含 CPU 成本，但主要 policy comparison 按协议报告 reward / step，不混为一项。
- actor 89 B、完整 package cap 262,144 B。策略主 cohort 6,144,000 步，pilot 92,160 步，合计 6,236,160；授权总额 / 剩余额度：UNKNOWN。calibration 属 H023，不重复计入。
- 全部源码、配置、日志、报告和 run provenance 从 [E123](../../experiments/exp123/README.md)、[E124](../../experiments/exp124/README.md) 链接；protocol clarification 说明共同 harness 会清空 actor Adam moments，shared PPO 并非外部 PPO / SOTA 复现。

## 当前边界与下一决策

本轮不支持该特定 learned-selector 组合优于 intercept，也不支持其超越 direct shared PPO；没有检验超出已给方法集合的普遍不可能性。按 H025 / H026 的机制优先安排后续；不添加更复杂 selector，也不将树 / DAG 作为已经进入的确认方向。下一轮须单独冻结候选、特征和新 seed，并保留当前强基线。
