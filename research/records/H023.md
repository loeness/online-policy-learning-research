# H023 · 所选反馈中的历史特征预测价值

- 当前科学状态：TESTED（保留原状态，不等于假设得到确认）。
- 原始协议日期：2026-10-19；本生命周期摘要于 2026-10-20 回溯补入。
- 提出者：UNKNOWN；原始 H 独立登记日期、初始 PROPOSED 状态及逐次状态历史：UNKNOWN。不得把本次回溯摘要称为预注册。
- 原始证据来源：[探索性冻结协议](../../docs/RETENTION_VALUE_STREAM_PROTOCOL.md) 与 [结果审查](../../docs/ORDERED_RETENTION_VALIDATION_REVIEW.md)。

## 原始问题、主张与机制

在真实部署式、只能看到已选操作反馈的流中，有限过去特征能否比按 action 分开的常数预测器更好预测所选保存操作之后的 factual outcome？未选动作标签始终缺失，故预测改善不等于因果写入收益，也不回答完整保存策略是否改善。后者是相连但独立的 H024 问题。

## 原始可观测预测与判别规则

主比较是 calibration 流最后 32 / 64 个事前预测的 prequential squared error：linear − intercept MSE < 0 对历史特征模型有利。正式的最小 MSE 差或确认阈值：UNKNOWN；协议将六 seed 结果标为 exploratory，并明确“不据结果自适应调参”。单列 reward / step 的 +0.002 实际参考适用于策略效用，不是此 MSE 检验的通用门槛。

## 轮次配置、比较与预算

- 环境 / 数据：固定预训练基础、两槽 local cache 与一共享 parent 的小型导航任务族；dynamics / reward_conflict 两关系。6 个 unused calibration seed、每关系 64 个决策，共 12 流 / 768 个所选标签；uniform random action propensity 为 1 / 4。
- 模型：四个 action-specific discounted ridge 估计，ridge 1、discount 0.97；线性模型见 6 个过去特征，intercept 仅 bias。只在每个 1,536 步三 bout 反馈后更新选中动作。目标 utility 为 reward / step 减 measured decision-and-block CPU seconds / step，lambda_cpu = 1。
- 指标方向：末段预更新预测 MSE，越低越好；按 seed 聚类、关系分层。policy return、CPU、回合恢复和包容量为辅助事实，不能替代主要 MSE。
- 完整包上限 262,144 B、actor 89 B。calibration 主流实际 1,216,512 步；plumbing pilot 9,216 步。已知这两者合计 1,225,728 步；授权上限 / 剩余额度：UNKNOWN。比较阶段是 H024，不计入此 E。
- 运行及输入来源见 [E121](../../experiments/exp121/README.md)、[E122](../../experiments/exp122/README.md)，[协议 / 配置 / 方法 / runner](#原始来源与实现)，run SHA 与数据身份由 linked run provenance 承载。

## 分阶段历史与事实

| 实验 | 角色与状态 | 事实摘要 |
|---|---|---|
| [E121 · calibration pilot](../../experiments/exp121/README.md) | pilot，COMPLETED | 1 个四决策流、9,216 步；只校验 plumbing 与账本，不计作效能证据。 |
| [E122 · 随机流校准](../../experiments/exp122/README.md) | calibration，COMPLETED | 12 流、768 标签、1,216,512 步；所有选中标签与历史预测保留。 |

后半段 prequential MSE 差 linear − intercept 为 −3.0619875e−6，描述性区间 [−4.3653208e−6, −1.4695639e−6]。整体误差下降约 5.7%；reward_conflict 有改善，dynamics 平均恶化约 3.1%。该证据支持部分环境中的所选结果预测改善，但不支持跨关系一致优势。

## 当前边界与下一决策

此 H 的待解释目标已经回答为“有条件的预测信号”，不是确认一个可部署保存器。它没有逐次未选动作 outcome、动作因果增量或全流策略的独立价值证明。后续 H025 对预测误差来源、H033 对 action contrast 的计划属于新的关联问题；回到此 H 应先处理共享奖励变化与操作差异如何分开，不能把本 cohort 的标签再当成独立确认。
