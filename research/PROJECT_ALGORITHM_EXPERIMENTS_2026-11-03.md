**整理时间：2026-11-03（Asia/Singapore）。** 本文综合“算法实现”“消融实验（1）”对话，以及研究索引、方法合同、实验报告和已保存审计。它是研究状态与交接文档，不是新实验、预注册、对所有历史原始数据的重新审计或论文定稿。具体假说的原始预测、代码身份、失败及后续修订，以各 H/E 记录为准。

**当前判断：**受控实验表明，真实在线学习产生的共享参数可以承载部分可复用知识，但错误迁移和新旧行为取舍同样存在。未来任务复现分布会影响保存操作的结果。现有证据尚未证明：自主保存选择器稳定优于强简单基线，树拓扑本身带来额外优势，或当前方法在公平的完整容量与计算预算下具有可推广的奖励增益。H026、H033、H036 均仍为 **INCONCLUSIVE**；E165 尚无科学结果，且其冻结检查包有一处需要修复的测试断言。

## 1. 研究问题与范围

核心研究对象是：预训练初始化后，策略通过真实在线交互持续更新，在有限持久容量、有限历史和任务切换条件下，如何形成、共享、整合、写入、淘汰和保留知识，使任务回访时能够恢复并继续学习。需要分别判断**表示是否能承载知识、写入什么、何时写入、何时保留或替换、最终序列化后及后续学习是否仍有净收益**。

树、扁平分组模块库、DAG 是用于组织共享知识的候选结构，不是预设已经成立的创新结论。近期重点实验使用已知任务、逻辑组及边界的受控设置；早期部分路由或分组实验不能与后期保存实验直接拼接成已经完成的无标签系统。当前以小型导航、动作重映射及受控关系为主，不能直接外推所有环境或未知新技能。

完整索引：[研究总索引](RESEARCH_LOG.md)、[实验总索引](../experiments/README.md)；早期详细来源、证据和局限：[2026-10-20 研究复盘](RESEARCH_REVIEW_2026-10-20.md)。历史分类不是对每条旧工件重新执行的独立确认，部分历史 commit、命令和来源仍有缺口。

## 2. 当前受控算法与结构

### 2.1 预训练底座、局部槽与共享父槽

近期保存实验使用冻结的预训练策略及源输出基 W0。一个 learner 持续与环境交互并根据实验设置做 PPO 更新；当前任务的策略通过局部残差和其可调用的共享父修正表示。两个局部槽各有 **27 个系数**，可视为三个 band 的 3×3 矩阵；一个共享父位置包含 **9 个系数**，可广播到 band。该低维表示及输出基是该环境的任务先验，不意味着能从中学到 W0 表示之外的任意技能。

父槽可不绑定、绑定某个逻辑组，或以 wildcard 对多个组生效。局部槽受限并可淘汰、重用；新的槽初始化时能否调用父矩阵，取决于实际 binding。共享父因此可能在局部残差消失后的初始化和继续学习中发挥作用；受控的 `local=0` fresh-slot 评价只是其行为代理，不能当作已经执行了真实回访奖励实验。

父矩阵变更会对受影响的驻留局部残差做补偿，使其**编码前**的有效策略近似保持。随后仍要使用完整 actor codec 编码、解码，再实测驻留策略漂移与 fresh-slot 行为。补偿不保证量化后完全不变。安装后会按规定清理 actor 对应优化器状态，保留 critic 等其他需要继续学习的状态；具体合同以运行版本为准。

近期 actor 的 int8 容器为 **89 B**；完整持久 learner 包上限为 **262,144 B**，包括 foundation、序列化 checkpoint、actor 和所需 evidence 等。89 B 不是整个智能体、训练内存或完整 learner 的大小。教师、候选拟合工作区、诊断及缓存属于运行成本，不可悄悄当作免费部署状态。来源：[保存流方法](../docs/RETENTION_VALUE_STREAM_METHOD.md)、[保存操作](../src/online_rl/storage_decision.py)、[H036 输入与评分方法](appendix/H036/METHOD_V1.md)。

### 2.2 保存动作与历史对照

保存流中比较过 keep（保留已有父及绑定）、replace（安装当前新候选并绑定其来源组）、mean（将旧父与候选平均并以 wildcard 覆盖）及 none 等动作。更大完整流也包含固定策略、随机、基于历史频率或保守下界的规则、学习型选择器、直接 shared PPO 和独立局部学习。各实验以其各自冻结版本为准，不能把所有动作或设置假定为同一实验。

H026 行为候选使用来源的有限真实观测，在冻结表示下拟合九系数父矩阵，使候选更接近来源策略行为，再和参数平均及 keep 比较。拟合不使用未来奖励；但来源教师本身已经由在线交互学习，同一时间流的留出诊断也不是新环境独立确认。E161 的 replace 候选只绑定新组，不能误写成 wildcard 同时保护旧组。来源：[H026 记录](records/H026.md)、[行为拟合实现](../src/online_rl/retention_behavioral_candidate.py)。

### 2.3 H033：操作前选择诊断

H033 的最小 E162 诊断固定三个操作前特征：有限近期历史中的新旧组访问频率差；新教师相对 W0 和行为候选的 KL 改善；旧任务 local 清零时旧父先验与无父 W0 的行为差异。目标是 6,144 步 `replace_behavioral−keep` 的配对增量，按 old-major/new-major 和 replicas 等权；16 个 seed 分层做四折整 seed 留出，岭回归 α=1，并与固定 keep、固定 replace、训练均值及频率规则比较。balanced 是次要评分。不能把未来分支或 observer 日志当成部署时免费输入。E162 是已见 E161 数据的探索性离线诊断，原 H033 更完整的双重稳健反馈及在线方法并未因此实现或验证。[H033 方法](appendix/H033/METHOD_V1.md)、[E162 报告](../experiments/exp162/analyses/analysis001/report.md)。

### 2.4 H036：旧行为保护拟合及限制

H036 在相同九系数父容量下，为新来源行为拟合加入旧行为保护项，并使用 wildcard binding，使旧组在 local=0 时也可以调用该父候选。**旧教师是旧组重新分配、local=0 时已解码旧父产生的 keep 初始化 prior；不是已淘汰来源的完整历史策略。** 新教师来自两个当前 resident 来源的有效策略。

新来源每个 owner 取固定 128 行，旧组取 FIFO 最新 128 行，均按时间顺序前 96 训练、后 32 留出。定义新行为 KL 为两 owner 均权、各自训练均值，旧行为 KL 为旧训练行均值；`M` 是两个新来源、三个 band 的有效矩阵均值。原 H036 目标为：

```text
L_lambda(C) = K_new_train(C) + lambda * K_old_train(C)
              + 1e-4 * mean((C - M)^2)
C0 = float64(float32(M)); lambda = 0 或 1
```

C 为 λ=0 的新拟合候选，D 为 λ=1 的保护候选；C0 是初始化、新训练 KL 约束的参照及必要回退，三者不能混用。原实现从 C0 使用有界 L-BFGS 搜索完整目标；closure 中满足 `K_new_train ≤ K_new_train(C0)+1e-12` 且目标达到当前最优的点才更新返回 incumbent。**该筛选不改变 L-BFGS 的目标和梯度，因此不是完整求解受约束优化。** 选定点转 float32 后再复查原新训练 KL 界，失败回 C0；不以留出结果重新选择。再用 wildcard 补偿安装、完整 actor 编码解码和 fresh local=0 评分。见 [H036 方法 v1](appendix/H036/METHOD_V1.md)。

## 3. 实验的一般流程与证据口径

1. **提出可证伪问题并冻结比较。** 登记 H/E、输入、候选、binding、基线、种子、统计指标、成本、停止/推进规则；检查实际环境和完整字节预算。冻结代码身份须包括 Git 提交之外的相关 dirty 文件与快照。
2. **获得相同的前缀。** 受控强化学习实验从共同 learner/环境状态出发，保存 checkpoint、evidence 和来源/代次；不同动作从共同 prefix 分叉。未来日程、observer 对照分支和留出评价不进入被测试的在线选择器。
3. **执行动作并测量后果。** 可比较 keep、replace、mean 等，记录完整编码后的策略、后续环境交互、持续学习、任务复现以及需要的恢复指标。环境交互、训练更新、CPU、墙钟、GPU、持久包、工作内存与磁盘是不同成本。
4. **统计与独立审查。** 根据预先定义的独立单位、配对及门槛分析；分支、replica、时间步或同一 seed 的不同评分包不能冒充独立 seed。保留所有样本、失败、原始工件、源码与输入身份、日志和资源缺口。
5. **决定并停止。** 将技术有效性与科学支持分开；结果可以为 keep、停止、阴性或 inconclusive。旧实验的预留不自动结转。当前约定由用户手动转达主控、算法实现和消融实验三方信息；验证交付、主控分析及算法侧分析完成后，本轮停止。

后续所有实验、合成／冒烟运行、拟合评分、正式统计及审计由消融实验在指定 SSH 项目环境执行；本机只用于编辑、静态核对和人工阅读回传证据。不得查看或修改其他账户资料。历史本机运行保留其真实执行位置，不改称远端。

## 5. 最近完整研究链：E161–E164

### 5.1 E161：H026 行为候选独立确认

早期 H026 探索中的 dynamics/late 条件，behavioral−mean 为+0.003394、behavioral−keep 为+0.003254 reward/step；这来自6个 seed 的探索且 late 同时改变多种状态因素。E161 冻结方法后使用 **16 个新 seed、288 条分支、2,244,608 次交互**进行独立确认：

| 主比较 | 平均增量 reward/step | 单侧95%下界 |
| --- | ---: | ---: |
| 行为候选 − 参数平均 | +0.001591 | +0.000045 |
| 行为候选 − keep | +0.001301 | −0.001132 |

预设联合确认要求两项单侧下界都大于零，且两项点估计都至少+0.002；结果未通过。旧任务占多数时相对 keep 为−0.005452，新任务占多数时为+0.008054，提示平均值受未来分布影响。H026 保持 **INCONCLUSIVE**；不补 seed、不启动完整流。未通过门槛不等于证明效应为零。[E161 结果](../experiments/exp161/analyses/analysis001/report.md)、[H026](records/H026.md)。

### 5.2 E162：H033 最小排序器

复用 E161 的16 seed，四折按完整 seed 留出、0新交互；ridge 相对 keep 的增量+0.002033，但相对最强简单频率规则仅 **+0.000720**，低于预设+0.002；四折最差基线差严格为正仅 **1/4**，低于要求3/4。固定三特征／岭回归诊断为 **NO_ADVANCEMENT**，H033 为 INCONCLUSIVE。bootstrap 是对固定留出结果的条件性描述，不包含重新拟合训练不确定性；完整 CPU 成本存在 UNKNOWN。不能外推成所有过去信息都没有价值。[E162 报告](../experiments/exp162/analyses/analysis001/report.md)。

### 5.3 E163：旧行为保护机制筛查

使用相同16个固定 prefix，C/D 各拟合一次，共 **32次 fit、0新交互**。编码后的 fresh-slot holdout 联合筛查要求旧 KL 至少相对 C 降低25%，新收益至少保留 C 的50%，并有非零／正收益条件；预设至少12/16通过。实际 **8/16**，低于门槛，因此固定 v1 **NO_ADVANCEMENT**。总体均值 `K_old: 1.17558 → 0.26965`，`G_new: 0.12650 → 0.08781`；`G_new=K_new,W0−K_new` 是拟合代理，不是奖励。

8项通过中有1项D返回C0，不能把它归因于保护优化更新。失败原因存在重叠：3项C无正新收益、2项旧KL保护不足、5项新收益保留不足；不能直接相加为独立失败数。所有 actor 为89 B，完整包为233,500–234,681 B；编码后驻留最大概率漂移最高约0.2184，表明须单独检查编码影响。

首次 run001 在科学 worker 启动前因资源计量不一致停止，为 **ACCOUNTING_INVALID**，完整成本 UNKNOWN，不能记为0/16或科学失败；经单独授权的 run002 有效。run002 观测 CPU 8.625535秒、footer前墙钟10.011705秒；包含未观测收尾保留的保守上界13.625535／20.011705秒。因 run001，E163 累计完整成本仍 UNKNOWN。来源：[E163 报告及逐项表](../experiments/exp163/analyses/a002/report.md)。

### 5.4 E164：接纳与回退的同轨迹诊断

E164 不是新 seed 确认。V 是原候选加转后 gate；UG 在同轨迹选未经过 closure 筛选的完整目标最优候选，但保留转后 gate；UR 使用同一候选并诊断性绕过 gate。预定16个逻辑配对，11项按候选身份复用，5项恢复参数，共 **5次 fit、10个新评分包、0新交互**。UG−V 隔离在转后 gate 保留时的交付变化；UR−UG 隔离同一候选的转后复查效果。UR−V 同时改变两项，不可作为单因素归因。

| 编码后留出，按全16项平均 | 旧 KL Δ（低为改善） | 新收益 G_new Δ（高为改善） |
| --- | ---: | ---: |
| UG−V | 0 | 0 |
| UR−UG | −0.221881（5改善/0退化/11不变） | −0.016072（2改善/3退化/11不变） |

5个恢复候选在 float64 阶段就违反 C0 新训练 KL 界；保留转后 gate 时全部回退，UG 与 V 最终字节相同。绕过 gate 释放旧保护改善，也带来异质新收益代价。旧 KL 改善幅度集中，最大3项贡献约91.6%；不能因某一项影响大就删点。11个精确复用零行不是11次独立阴性确认，5项条件均值也不能代替主分母或推断未来发生率。

状态 **COMPLETE_VALID / EXPLORATORY_ONLY**，H036仍 **INCONCLUSIVE**。最终审计通过，但原核验器存在事后映射修正；原失败记录及修订链保留，未重跑 campaign，不能说原核验器一次通过。观测CPU 7.929755秒、footer前墙钟9.350687秒；含收尾保留上界12.929755／19.350687秒，精确完整footer及未测运维CPU为 UNKNOWN。[E164 结果与审计](../experiments/exp164/analyses/a001/report.md)、[主控分析](appendix/H036/COORDINATOR_E164_SYNTHESIS_20261023.md)、[算法分析](appendix/H036/ALGORITHM_E164_ANALYSIS_20261023.md)。

## 6. E165：已设计但尚未获得结果

### 6.1 目标与固定比较

E165 延续 H036：固定九系数父、教师、数据与原 C0 新训练界，检查既有参数所构成的有限路径中，是否存在 D 没交付的旧保护改进。它不是完整九维可行域搜索、生产保存器确认或奖励实验。C/D 为 E163 最终 float32 参数；U32 为 E164 UR 候选，5项读取保存端点、11项按已核验身份引用 D；不能从 hash 恢复缺失参数。

固定线段及目标：

```text
X_j = C64 + 2^(-j) * (float64(U32) - C64), j = 0,...,15
L1(X) = K_new_train(X) + K_old_train(X) + 1e-4 * mean((X-M)^2)
b = K_new_train(C0); feasible(X) iff K_new_train(X) <= b + 1e-12
```

| 臂 | 固定搜索规则 | 最终处理 |
| --- | --- | --- |
| S0 | 依顺序选第一个 `L1(X_j)<L1(D)` 的点 | 转float32后按原新训练界复查；失败回C0 |
| S1 | 第一个同时满足 `L1(X_j)<L1(D)` 和原新训练界的点；越界继续缩步 | 同S0 |

均未找到时保留 D，严格平局不替换 D；转后回退不继续搜索。S1−S0 是有限搜索中约束参与停止的主比较，另报 S1−D，防止把 S0 退化当作原方法改进。全16 prefix 先完成训练选点与锁定，再验证固定26201 D评分锚点，再评锁定臂；不得用 holdout 或未来信息选点。S0/S1 最终恰回 C0 时仍须作为既定臂评分或按完整身份准确别名；删除的是额外独立 C0 参考臂。

正式**见证只统计 S1**：最终 float32 候选与 D 字节不同、满足原新训练界，且 `L1(S1)<L1(D)-1e-8` 与 `K_old_train(S1)<K_old_train(D)-1e-8` 均成立。这些阈值用于报告，不控制搜索。至少一个见证说明该有限候选族存在原D未交付的局部改进；没有见证不证明容量不足或不存在其他可行解。编码后可行、旧／新留出改善和环境 reward 是不同层次；已见 holdout 的复用结果仅具探索性。

全批限制：0真实重新拟合／恢复、最多336次真实 prefix 训练 oracle、最多33个完整评分包（含D锚点），相同身份的缓存与别名可减少实际开销。完整计划／实现见[E165 方法](appendix/H036/METHOD_BUDGETED_V1.md)、[主控合同](appendix/H036/COORDINATOR_E165_CONTRACT_20261024.md)。

### 6.2 科学源码冻结与新发现的检查问题

算法方冻结36项源码快照，声明 identity `4e96df16ca207ea961bafaed6b92dfbee07d7cdd55dc7cf986b5fb2b48189f0b`；逐项字节／SHA及9个预定测试节点的静态身份已核对。这说明文件身份可追踪，**不代表测试或科学验证通过**。

算法对话随后静态发现第4项合成测试断言与方法合同冲突：[冻结测试](appendix/H036/delivery_budgeted_v1/source_snapshot/tests/test_retention_budgeted_search.py#L614)中，C0对应界 `b=3`，S0搜索选择的 `X=3` 对应新训练KL为4；S0可以在搜索时选择它，但共同的 float32 复查应使其回退到 C0=0。原测试却要求S0最终值为3。建议保留同一场景，分别断言搜索选择／raw cast为3、回退为true和最终值为0；S1按场景继续缩步。该问题是**静态推导的测试断言矛盾，不是已实际发生的远端测试失败，也不是算法机制阴性结果**。

应由算法实现修正测试并生成新的冻结版本与身份，保留旧快照和证据；验证方重审新的清单、控制及正式见证统计只计S1。此前旧版本的检查/传输清单不得被默认为新版本身份；具体准备和执行指令须与实际接受版本重新绑定。详见[科学冻结清单](appendix/H036/delivery_budgeted_v1/manifest.json)、[CHECKS 规格](appendix/H036/delivery_budgeted_v1/CHECKS_SPEC.json)。

## 7. 已有结论、贡献候选与边界

**已有局部机制证据：**在线更新可被共享参数承载；在特定受控设置下，父结构可帮助局部淘汰后的复用；知识可能发生负迁移；保存决策收益随未来任务复现分布而变；E164 把有限候选的旧保护／新拟合取舍与接纳路径具体化。

**可能的研究贡献，但尚待证明：**围绕有限在线证据与真实完整字节预算，设计兼顾旧／新行为兼容、淘汰后恢复和继续学习成本的保存机制；构建可归因、保存失败与强基线的共同前缀分支评估。文献中已有在线共享、蒸馏、模块组合及树／适配器相关工作，不能把“共享残差＋树＋蒸馏”简单称作首创；此前文献比较范围见[研究复盘](RESEARCH_REVIEW_2026-10-20.md)。本文未重新做穷尽性新颖性检索。

**不能从现有证据得出：**树拓扑独立带来优势；fixed ridge、旧lower gate 或当前H036 v1是可部署的普遍更优选择器；共享方法在最优重新分配后的同完整字节预算下达到容量 Pareto 优势；E164证明必须扩容／放松代价；KL或训练见证等同环境奖励。用户提供任务或组标签的结果，也不能声称解决未知情境识别。
