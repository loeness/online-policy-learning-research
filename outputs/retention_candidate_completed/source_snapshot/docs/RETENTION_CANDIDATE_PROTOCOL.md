# 候选内容与较晚在线状态：运行前协议

日期：2026-10-20。角色：探索性机制验证。配置为 `configs/retention_candidate.json`。

## 问题与可观测预测

上一轮没有建立仅延长反馈窗口即可改善保存选择的证据。本轮检验：

1. 在相同 9 个共享系数下，基于有限观测的行为拟合是否比所有来源和 band 的参数等权平均更好地保留当前局部策略的行为。
2. 函数拟合改善是否转化为保存后自然淘汰、恢复及继续学习中的奖励改善，而非只降低拟合误差。
3. 早期结果是否覆盖较晚在线状态；较晚状态是否改变候选构造与保存操作的后果。

本轮先不训练更复杂的保存选择器。当前状态编号、任务编号和切换边界由实验提供。这里的替换和合并是一次干预；继续学习期间共享父参数固定，局部 PPO、critic、LRU 淘汰继续。

## 因素与来源

六个新种子 25201–25206，仅根据映射选取：旧家族 A/B 各三，奇偶各三；不查看回报。偶数使用 old_major 历史，奇数使用 new_major。两种关系为 dynamics / reward_conflict。每个种子、关系下分别构造 early 与 late 两种前缀。

early：两个旧来源各 1024 步，建立 group 0 的算术均值父参数，补偿当前局部修正，执行 int8 编码并清理优化器状态；再运行八个历史 bout，前六个各 512 步，最后两个新来源各 1024 步。合计 7168 步。

late：同样 bootstrap 后，增加四个在线 warmup 周期。每周期先运行 group 1 的两个来源，再运行 group 0 的两个来源，每 bout 1024 步。group 1 只作局部在线学习，不覆盖共享父参数；每完成 group 0 的一对来源，按固定 replace 规则把当前有效矩阵均值写入 group 0 的父参数，同时补偿、编码并清理优化器状态。旧来源在自然淘汰后重新出现时可以继承已有父参数并继续修正，形成积累的旧共享状态。随后运行相同历史模板，前六个各 512 步，最后两个新来源各 4096 步。合计 29696 步。

这是运行前静态设计审查的修改：如果在唯一父位置交替保存两组知识，则每次旧来源重现前其父知识已经被覆盖，不能代表希望检查的累积旧共享状态。固定的 group 0 写入只用于构造这一受控状态，不作为新的自适应组织算法，也不根据奖励选择。

因此 late 同时改变在线年龄、已有父知识、critic、来源拟合量和访问历史。本轮只判断状态覆盖与该组合条件的结果，不能将 early/late 的回报差解释为单独增加拟合量或成熟时间的因果效应。各状态内部所有保存操作从完全相同的学习器和模拟器分叉。

## 有限观测与行为候选

在最后两个来源的最终 rollout 完成时，分别保留最后 128 个实际观测，合计最多 256 行。每行保留 owner、slot、generation、bout、global step 等来源索引；不从完整原始日志回读并补充拟合数据。完整日志仅供外部审计。

教师为分叉时两个当前驻留来源的有效策略，包括已有共享修正。对各自保留的观测计算教师分布；教师不访问未来奖励、模型分支、未发生状态或任意环境重置。冻结底座和 source basis，用一个共享 3×3 系数矩阵拟合这些分布。

按每个 owner 的时间顺序，前 75% 行训练，后 25% 行作诊断留出；来源等权。目标为教师到学生的 forward KL，加 `1e-4 * mean((C-C_mean)^2)`。初值是两个来源、三个 band 的算术均值。使用 PyTorch 的确定性 L-BFGS 和 strong-Wolfe 线搜索，最多 64 次迭代；在 closure 中硬性限制 256 次目标评估，避免线搜索越过名义预算。初值与已评估点中的最佳训练目标值比较后返回；留出误差不能决定候选选择、步数或超参数。分布包含原策略的 temperature 与 epsilon 混合。

256 次上限针对优化器 closure；初始和最终目标的诊断计算另计并记录，总 CPU 包含它们。返回值为实际安装的 float32 系数，最终误差按该返回值计算。

留出行仍来自同一在线时间段，具有相关性，只是拟合诊断，不是独立环境泛化或策略价值标签。教师已经通过这段交互在线学习，留出不代表教师未见过的数据。拟合不改善时也保留结果，不依据正式回报重新调参。

## 候选 × 组织规则

每个前缀比较五个分支：

| 分支 | 新来源候选 | 保存操作 |
|---|---|---|
| keep | 不使用新候选 | 保留当前父参数及绑定 |
| replace_mean | 参数平均 | 替换父参数，绑定新 group |
| replace_behavioral | 行为拟合 | 同样替换与绑定 |
| merge_mean | 参数平均 | 与当前父参数各半平均，wildcard 绑定 |
| merge_behavioral | 行为拟合 | 同样各半平均和 wildcard 绑定 |

merge_behavioral 只改变新来源候选的构造；并没有对旧父知识与新知识联合蒸馏。因此它不是解决所有冲突的函数空间合并算法。keep 无额外编码；其他分支均执行一次补偿、编码与优化器清理。编码前的驻留函数保持及编码后的漂移另报。

每个前缀交叉两个未来比例 × 两个随机续程 × 五操作。未来随机种子为 `50000000 + 1000*seed + replica`；同一条件各操作共享随机流，当前物理回合不重置。未来每条实际 6144 步，嵌套报告 1536 / 6144 步。

未来比例仍与历史交叉；不能把已知未来下的最佳操作当成可部署选择器。频率、直接共享 PPO 与之前的完整流实验保留在档案中，本轮不把一次冻结父参数的干预冒充它们的重复在线更新对照。

## 实际预算

actor 容器固定 89 B；底座、完整学习器状态、优化器、原有有界证据、actor 和新来源观测 sidecar 合计必须 <=262144 B。五分支保留相同来源缓冲并按实际序列化字节收费。不能只把 9 个 float 当作完整持久预算。模拟器状态和完整审计日志是外部评测资料，不供部署算法使用。

候选拟合的 CPU/墙钟、来源缓冲字节、主要数组工作区与优化器工作区口径另报；候选数固定，拟合结束不永久保存两份候选或教师副本。数组工作区不是完整进程峰值 RAM 的等价指标。报告一次性共同前缀成本和各分支继续学习成本，避免把共享前缀重复收费。

正式预期：24 前缀、480 分支，442368 前缀交互 +2949120 分支交互 =3391488 次实际仿真交互。pilot：两个前缀、十个分支，共 98304 步。失败运行的实际交互另行累计并保留，不覆盖原目录。

## 判据与统计

先通过软件测试和 pilot 审计：函数保持、拟合梯度/epsilon 一致性、输入不变、完整恢复、来源代次、来源观测来自最后 rollout、父参数冻结、编码一致性和容量。训练目标不能比初值更差；留出和奖励可变差且必须如实报告。通过技术核对后按冻结配置执行全部正式条件，不能依据 pilot 回报选择配置。

主要回报对比为 6144 步内 `replace_behavioral - replace_mean` 与 `replace_behavioral - keep`，按两类关系与 early/late 分层。补充 merge、恢复首 256 步、1536 步窗口、CPU/容量、拟合 KL 与编码后 KL。六个部署种子为独立单位；其他因素先在种子内配对汇总。描述性 95% bootstrap 按旧家族 A/B 分层，各三种子，10000 次重采样。多条件探索不作为经多重比较调整的确认结论。+0.002 奖励/步只作为预先列出的实际量级参考。

进入新算法确认需要：同预算候选比平均构造有可重复的奖励增量，并且与 keep 的比较有清楚条件支持。只有拟合误差降低，或只有相对更弱操作的优势，不建立保存组织创新。若奖励没有改善，优先检查状态分布覆盖、教师质量和共享表示能力，不继续堆叠选择器复杂度。

## 相关方法的定位

行为压缩借鉴 [Policy Distillation](https://arxiv.org/abs/1511.06295)、[Distral](https://arxiv.org/abs/1707.04175) 中共享行为的思路；快学习后压缩的阶段分工与 [Progress & Compress](https://arxiv.org/abs/1805.06370) 有联系。此处没有完整复现这些论文：学生仅 9 个修正系数，教师为当前在线局部策略，来源观测有硬预算，并将候选构造和一次保存操作分开验证。行为蒸馏本身不是本项目的新贡献。
