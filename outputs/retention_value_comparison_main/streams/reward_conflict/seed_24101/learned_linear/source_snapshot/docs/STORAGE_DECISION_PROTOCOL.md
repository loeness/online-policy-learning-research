# 单个共享位置的保存决策：冻结验证规程

日期：2026-10-18。配置为 `configs/storage_decision.json`。

## 研究对象与停止条件

本轮把一次知识保存决策落实为：只有一个可复用共享模块位置时，保留原模块，还是把新在线知识保存进去？预训练底座相同，候选均来自随后真实在线 PPO；未来继续参数学习。

首先判断这个决策在当前表示和任务族中是否确实影响后续学习，再判断仅凭过去证据的选择是否有用。本轮不预设新筛选算法获胜，不再次验证此前已建立的普通迁移结论。若行动价值没有稳定区别，则停止增加收益门控，不将相关系数或软件检查当成核心方法成果。

## 1. 持久结构与已知信息

- 两个局部槽，每槽27个系数；一个共享模块，9个系数。当前有效修正仍为 `M = A + C`。
- 同一 int8 actor 编解码，物理容器89 B。全部行动拥有相同参数形状和保存字段。
- 局部槽按 LRU 自然淘汰；任务数超过局部槽数。共享模块在决策后冻结，所有未来经验用于局部 PPO 和公共 critic 更新。
- 任务编号、切换时刻和 old/new 组关系均作为机制控制，统一提供给所有方法。没有验证未知情境发现。
- 可部署选择器只读前缀中的有界状态：每组最近256条已定稿的行为证据、最近8段组编号及计数。完整原始日志和未来日程不供其读取。

完整持久包包括 W0、actor sidecar、critic、优化器、缓存、证据和随机状态，上限262144 B。报告各分支实际字节，而非把共同上限写成字节恰好相等。临时3×3候选工作区36 B另记。移出的父模块不能保存在 learner 备份、动量或日志查询接口中。

这是固定 actor 布局中的保存选择，不声称基线不能把总包预算以其他方式重新分配。`none`保留同形状的零模块，属于去除共享内容的因果对照，不是全局最优存储基线。较小局部残差不计作实际释放容量。

## 2. 共同在线前缀与候选形成

使用固定的一个历史 W0。每个新部署 seed 独立初始化环境、动作与 PPO 抽样随机状态；多个部署 seed 不当作多个预训练模型。

每个 seed 有两种关系：

1. `dynamics`：old/new 分别为不同 A/B 动力学家族，奖励均为正。
2. `reward_conflict`：old/new 具有相同动力学家族，奖励符号相反。

用 `default_rng(seed + 81001)`选择 old 家族；动力学关系的 new 为另一家族；奖励冲突的 old 符号从±1中抽取，new 取反。提供的组信息是受控条件，不能解释为奖励辨识已完成。

先依次在 old 的变体0和1各在线学习2048步。从两个仍驻留局部槽、三个band的有效修正取平均，形成 old C。写入时补偿局部参数，保持驻留有效策略。

再经过8段、每段1024步的在线历史；`(组,变体)`模板为：

- old_major：`(0,0),(0,1),(0,2),(0,0),(0,1),(0,2),(1,0),(1,1)`。
- new_major：`(0,0),(1,0),(1,1),(1,2),(0,1),(1,2),(1,0),(1,1)`。

两个前缀都以 new0、new1结束；新候选 C 从这两个仍驻留槽的有效修正平均得到。候选不使用未来数据。每个预先定义的 case 均纳入，不按候选收益或将来的行动差距挑选检查点。

新分配局部槽在已知组匹配被保存父模块时立即继承它；既有局部槽不反复叠加先验。前缀中只有 old 模块可复用，新知识保留在当前局部参数中，直至形成候选并作决策。

## 3. 四种实际行动

从同一完整前缀 checkpoint 和同一模拟器状态分叉：

| 行动 | 决策后唯一共享内容 | 之后允许继承的组 |
|---|---|---|
| keep | old C | old |
| replace | new C | new |
| mean | 两者等权平均 | old与new |
| none | 零矩阵 | 无 |

每种行动均先读出全部驻留槽的 M，再修改共享内容、绑定关系和局部补偿。编码前全部驻留策略保持不变；编码后真实行为漂移单独记录。结构选择的效果来自后续自然淘汰、复用和学习。mean是必要的简单整合对照，不能把它的好坏归因于额外参数容量。

每次分叉必须恢复 actor、critic、优化器与step计数、PPO排列 RNG、动作 RNG、torch RNG、LRU、代数、证据、父模块标签；另恢复真实模拟器的位置、目标、episode长度、RNG、计数及driver的obs/episode序号。观察者保存的未来日程与其他行动内容不进入 learner。

## 4. 后续在线过程与主要估计量

每种行动继续12段、每段1024步的真实环境交互和正常PPO，H=12288。rollout为256步，所有新行用于学习；固定学习率、温度、epsilon、critic和codec规则。每rollout清除actor动量，保留critic动量。切换任务不额外reset环境；仅完成或截断episode后reset。

old_major未来为三次 `(old0,old1,old2,new_i)`，i依次0、1、2；new_major交换组。每个共同前缀都运行两种未来，行动之间使用同一未来日程、逐raw-step动作均匀数以及按episode序号配对的reset种子。轨迹和PPO提前停止数可因策略不同而变化，实际计算分别计费。

主要结果为 H 内累计奖励以及对应每步奖励，包含复用、局部重学、自然淘汰及其行为后果。另列每段前256/512步、各组回报、淘汰数、PPO更新数和实际CPU/wall。前缀成本单列且各行动共同拥有，不把观察者重复运行算作部署算法免费能力。

定义 `D = R(replace) - R(keep)`。第一项机制预测是：

`I = D(new_major未来) - D(old_major未来) > 0`。

I比较同一前缀中未来复现分布如何改变保存选择的作用；不要求任意单个候选始终有利，也不把事后最高分支写成无偏最优价值估计。

## 5. 过去证据选择器与边界

冻结的比较规则：固定keep/replace/mean/none；最近8段频率较高组（平手keep）；最近出现组（当前为new）；历史surrogate gain；历史surrogate lower。

收益代理按行动的真实继承范围计算：old证据上比较零模块相对 old C，new证据上比较 new C相对零模块，再按最近8段组频率加权。gain或lower大于0时replace，否则keep；证据不支持时keep。沿用现有支持条件与误差惩罚，不通过本轮结果调阈值。这些是已有简单规则及诊断对照，本轮不将它们宣称为独创新算法。

这些历史行可能参与局部拟合和候选形成；它们不是独立留出证据。优势和经验lower也不是长期保存价值的无偏估计或安全置信下界。本轮检验的是使用这些输入的完整决策后果，不据其名称宣称校准或安全保证。

选择器在未来展开前冻结并记录；其结果由它选择的那个实际完整学习分支获得。这只适用于本轮单决策，不能冒充多次自适应保存算法。

- 主条件：history_regime与future_regime一致。检验过去频率在具有持续性的流中是否足以帮助保存选择。
- 压力条件：二者不一致。同一过去对应不同未来，不要求算法提前知道无提示分布逆转；测量这种假设失效的代价。

两种条件始终分别报告。不得把未来组别用作部署选择器输入。不得以future最优行动筛选样本、阈值或候选。

## 6. 固定判据与分析单位

主要 cohort：8个新部署seed，2种关系×2种历史，共32个前缀；各分叉2种未来×4行动。所有seed、条件和失败保留。

先对同seed同关系的两种历史取均值，再报告每个seed。跨seed配对差使用固定10000次seed-cluster percentile bootstrap，给出描述性95%区间；不把分支、任务或轨迹当独立seed。不声称这是事前功效充足的显著性研究。

机制的探索性有利判据：每种关系的平均I为正、至少6/8 seed I>0，并报告其区间；实际意义参考每步奖励0.002，阈值未由本轮结果调节。正向I仅表示保存决策具有与复现相关的影响，不构成新在线算法已成功。

同时报告偏好是否反转：`D(old_major)<0`且`D(new_major)>0`的case数，以及两种未来下D的逐seed均值。只有I>0而没有行动偏好反转，仍可能总选同一模块就足够。不能把响应幅度不同自动解释为需要自适应保存；后面的规则对照用于进一步判断。

过去证据规则是否有用，直接看它在主条件下相对全部固定规则以及频率规则的完整学习回报差，不用Spearman替代。只有同时优于keep和replace，才能说明其价值超出总选同一行动；mean也必须保留。报告所有差值和区间，不选择赢家后冒充独立确认。

若只有频率有效而收益代理未超越它，结论是当前实例有可利用保存决策、但复杂收益估计尚无独立价值。若所有选择几乎等效，则在本实例中缺少方法改善空间，停止围绕当前门控扩展。

若频率选择也无法优于keep和replace两个固定行动，则不因I为正而自动进入复杂门控；先区分候选质量不对称、简单mean占优和过去证据无预测力等情况。

## 7. pilot、软件、成本与归档

独立pilot seed20089，仅dynamics/old_major历史，bootstrap各512步、后续每段256步，覆盖全部未来/行动；仅检查软件路径、恢复、补偿、计费与容量，不选择方法。pilot及软件修复保留。

预期主成本：32×12288前缀 + 32×2×4×12288分支 = 3538944真实步骤。pilot为3072前缀 + 8×3072分支 = 27648步骤。其他真实仿真检查另记，不能静默漏计。
