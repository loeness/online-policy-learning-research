# C1 补齐之后的研究判断

原 A/B/C1 数据保留。此次完成的工作服务于“预训练初始化 + 部署后持续策略改进 + 有界持久知识”，没有进入 C2/C3。

## 1. 三项补齐改变了哪些结论

**在线经验有明显价值，但 C1 不证明必须靠神经参数更新。** 无历史的 W0 在实际连续流中平均成功率为 10.10%；利用真实转移更新的窗口计数达到 81.16%，两个排列后验模型达到 100%。后者不使用任务 ID、切换提示或隐藏映射，但获知三段可见 x 分区、网格边界、四方向和动作双射先验。它们逐事件更新统计状态，因此属于在线适应，不能称为“没有在线学习”。清空窗口会删除其在线证据；当前任务允许很快重新辨识，尚未形成持久参数的不可替代优势。

**树容器本身没有得到独特优势证据。** 把同一父/叶加法分解改写成扁平分组，成对 PPO 的动作、观测、logits、参数和 Adam 状态完全一致。C1 的正面证据应归于共享分解和匹配任务的结构先验。未来树的价值需要来自知识发现、整理、共享层级选择、容量满时的整合与替换；这些不能由一次固定树查表的性能代替。

**个别优化器和抗遗忘技巧没有自动解决问题。** 在独立验证后，主补充队列的低/高树最终六任务均值为 99.67% / 100%；低/高分组字典为 93.81% / 95.93%。部分字典种子仍有严重单任务失败。输入条件化的全参数模型为 34.80%，其 EWC 和行为回放改编分别为 18.27% 和 26.84%。这是有限搜索下具体实现的结果，不是全部全参数方法的上限。EWC 的相对保留率也可能因原先旧任务表现很弱而显得好看，必须同时报告旧任务绝对成功率。

**简单行为回放可能有负效果。** 主队列低档树加回放后，最终均值从 99.67% 降到 94.37%，立即旧任务成功率从 96.96% 降到 77.61%。它多存 128 条行为分布并增加计算，仍没有稳定收益。历史教师可能包含尚未学好的行为，均匀保持这些分布并不保证价值保持；这只是解释假设，未做因果分解。该实现是 PPO + KL 行为回放，未复现 CLEAR 的完整离策略算法。

## 2. 目前最有希望的容量改进

新种子 181/193/211 的共同低档比较如下。所有种子共用同一个 W0。

| 表示 | 最终六任务均值 | 六任务都 ≥80% 的运行 | 立即旧任务均值 | 修正及 Adam 张量 B* | 完整状态峰值均值 B |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原固定树参考 | 100.00% | 3/3 | 97.58% | 15,952 | 170,779 |
| 可训练共享源输出基 | 100.00% | 3/3 | 99.48% | 4,312 | 149,210 |
| 冻结源输出基，独立系数 | 95.68% | 2/3 | 92.09% | 2,748 | 146,893 |
| 冻结源输出基，家族共享 + 局部系数 | 100.00% | 3/3 | 100.00% | 2,972 | 149,344 |

*三种输出基方案另外保存 6 字节 seen mask，预算检查包含它；冻结的 780 字节基也包含在修正张量内。完整状态包含共同 actor、在线训练的 critic 及其 Adam、路由器、随机状态、rollout 和序列化开销，不等于进程 RAM。

在这个队列中，层级小系数相对原树减少约 **81.4% 的修正及 Adam 张量**，但完整状态只减少约 **12.6%**。在线 CPU 均值约 53.11 秒对 54.38 秒，计量包括日志和容量检查；差距小，不能宣布稳定算力或时间加速。其实际初始化路径冷迁移增益均值为 102.50，对原树 117.71；最终同为 100% 不表示每个迁移指标都更好。

这为“用共享表示保存更小的持久在线修正”提供了具体可用组件。冻结独立系数的一个种子降到约 87%，也说明容量缩小需要检查学习可靠性。完整各种子、候选、隐藏流和更强全参数情境头的结果见 [替代方案报告](../outputs/c1_supplement/alternative_results.md)。全参数情境头是一个共享 actor/critic 加六个小输出头，全部可训练；没有六张完整策略。它用于避免把最初弱条件化结构作为全部全参数方法的代表。

更强全参数情境头在这个新队列的最终均值为 **96.12%**，立即旧任务为 **79.43%**，完整状态峰值为 **236,589 B**；加 EWC 的对应值为 **80.61% / 70.41% / 316,003 B**。这些是比初版更强的具体对照，不能因初版结果差而忽略。两版全参数的正式种子和所选熵设置不同，因此跨队列差异不能严格归因于结构单一因素。

EWC 有一个清楚的收益：隐藏流之后强制根路由测试源 normal 行为，全参数情境头的源成功率从普通 PPO 的 **64.51%** 提高到 EWC 的 **96.29%**；四种低档表示为 **100%**，与各自同种子 W0 的轨迹回报完全一致。EWC 在该配置下改善源知识保留，同时牺牲新任务和旧 remapped 任务表现，应该表述为权衡，不能称为完全无效。强制根路由只说明源行为还可调用，不证明真实路由器会在陌生环境正确选择它。

保存的在线日志显示，层级输出系数首次达到滚动 20 回合 80% 成功率，A2/B2 平均为 **474 / 783 步**；原树参考为 **549 / 586 步**。所以它在 A2 更快、在 B2 更慢，不能概括为全面减少交互。所有方法正式训练预算仍相同，这也不是提前停止后终点性能相同的证明。

## 3. 为什么不能据此宣布通用压缩创新或 SOTA

源输出基特别适合动作重映射。[表达能力推导](C1_SOURCE_BASIS_DERIVATION.md)显示，四动作 W0 的每个排列都可用 3×3 对比空间系数表示。参数更新仍从真实奖励学习，并未使用隐藏排列来训练；但是表示先验与任务生成方式高度匹配。新奖励、新视觉特征或需要源策略从未表达的决策，可能超出该基的能力。

冻结低秩基之间训练小矩阵已有 [LoRA-XS](https://arxiv.org/abs/2405.17604) 等先例；在线策略共享基也有 [PG-ELLA](https://proceedings.mlr.press/v32/ammar14.html) 的相关思路。相似点是共享表示与小系数；当前不同点是部署真实奖励驱动的 C1 修正、固定家族共享、严格恢复状态计量及工作历史清空后的持久参数。这个组合诊断不能独立支撑“提出全新适配机制”的广泛主张。

此次比较尚不属于 published SOTA 的忠实复现。任务是一个确定性导航动作重映射族；每种方法只有三个部署种子，一个共同预训练权重；主要训练阶段提供 oracle ID，隐藏阶段使用此前带标签校准的模型库；全参数对照还有更大的容量。公开论文不同任务、数据和预算上的分数不能直接加入本项目排行榜。

## 4. 如何沿着原研究主题使用这些结果

可以把更小的共享基和系数作为未来知识节点的参数表示，同时保留真实在线更新和持续保存。这里的正面结果给出了一个值得使用的实现起点；不需要让每种情境保存完整策略。

当前尚未证明的核心贡献仍是：无标签历史中的潜在情境发现；在线决定共享/特化层级；把多处分散经验提升为通用知识；满容量后有价值的合并、压缩或替换；以及分别校准情境识别和策略改进的可靠性。它们正是原研究问题要求的知识形成与整合，不应被固定树或更小适配器的结果替代。

还需要在同一预先声明任务族中测量容量—经验曲线、重访节省的交互、累计在线表现及失败风险。此次所有正式神经运行仍固定训练 63,488 步；从保存日志提取的首次达到滚动 80% 成功率，只是适应速度诊断，不是“少训练到该步数后仍保持相同最终策略”的证明。

**学术判断：方向值得继续，但目前证据完成的是 C1 机制诊断与关键反例检查。最强新结果是有利任务先验下持久修正的容量效率；动态、有界、可靠的经验整合仍是需要实现并验证的论文核心。**
