# 文献启发后的定向验证：候选剂量、持久保存与未来学习

日期：2026-10-18。本轮沿用预训练后真实在线参数学习、有限持久容量的研究主题。阅读依据为[十二篇全文综述](literature/20261018_SYNTHESIS.md)，不将组件类比写成理论保证。

## 1. 文献真正改变了哪些待检验判断

| 依据 | 可以转化的判断 | 本轮实际检验 | 不能据此宣称 |
|---|---|---|---|
| FOLD 的序列内修正与跨序列写回 | 暂态携带与持久保存应分别干预；当前参数之和不变的转移可能只是重参数化 | 共同前缀下 replace/none；再分别继续 PPO 或关闭未来梯度 | 快慢参数分层本身是创新，或持久保存必然与在线梯度正协同 |
| Target Shift 对更新顺序的分析 | 候选内容会受来源学习量与顺序影响，必须隔离，而不能用“旧知识更成熟”解释全部结果 | 同一完整 learner 中，仅把 old 候选换成来源各训练 1024 或 2048 步时的内容 | 固定核平方损失的定理覆盖 PPO，或相同步数保证相同质量 |
| Sparse Forest 的受影响区域维护 | 先测当前维护是不是实际瓶颈，再决定是否重构 | 真实旧 checkpoint 上比较公共特征计算复用；零环境交互 | 已经实现局部结构维护，或具有端到端加速 |
| METIS 的带成本非平稳选择 | 保存操作应评价未来继续学习的效用，并计入失败成本 | 以完整学习分支评价已经冻结的简单保存规则；本轮未新增 UCB 规则 | 保存操作符合独立平稳臂模型，或未选行动的后果可以免费获得 |

具体迁移边界和原文细节见综述及四份分组笔记。本轮不重做十二篇方法，也没有进行它们的标准基准比较。

## 2. 三项实验的归因范围

### E0：旧候选拟合剂量

[冻结规程](SOURCE_DOSE_PROTOCOL.md)。8 个新部署 seed，四个仅按 mapping 选择的分层各两个；每 seed 两种关系×两种历史，32 个共同前缀。共同 W0、critic、优化器、模拟器和新候选完全一致。observer 捕获 old 来源各自第 1024 步之后的内容；原 2048 步内容照常参与完整前缀。干预只替换最终可保存的旧候选内容。

每个剂量展开 keep/replace/mean/none×两种未来，各未来 12288 步真实在线 PPO。两个局部槽、一个共享位置；actor 89 B，完整持久包上限 262144 B。replace/none 仅在完整 post-action learner+simulator hash 严格相同时引用同一物理分支，不能当作额外独立样本。

主要估计量 B 为两个剂量的 replace−keep 差异之差。均值≥0.002 reward/step、至少6/8 seed正、seed-cluster描述区间下端>0，才达到预设正向判据。另列主条件 history=future、反转压力条件，以及不预设方向的三重交互 Q。frequency 必须同时超过 keep/replace/mean 才能说明超越这些简单规则，不能用 oracle 分支最优值代替部署选择。

### E2：保存与未来学习是否存在交互

[冻结规程](LEARNING_INTERACTION_PROTOCOL.md)。沿用同一前缀和 E0 已计费的 PPO replace/none 分支，另外运行无梯度 replace/none×两种未来。允许真实动作轨迹、自然 LRU 淘汰和既有共享先验继承，不进行 actor/critic 梯度或优化器步骤。

令 S_train=R_replace,train−R_none,train，S_frozen=R_replace,no-gradient−R_none,no-gradient，T=S_train−S_frozen。这是本轮的新问题。T 为正才支持此设置下正交互；为负表示未来学习缩小了保存差距；两者都不能直接判断整个研究主题的真伪。区间必须完全超过+0.002或低于−0.002才称明确实际量级的交互。

无梯度分支从相同 post-action 状态启动，逐项核对 W0、critic、optimizer 与训练计数。没有重复生成前缀，也没有把无梯度 rollout 标为训练。计算不匹配，实际 CPU/wall 分开报告。

### 评分计算诊断：没有端到端省时证据

[干净计时报告](../outputs/score_feature_benchmark/report.md)。32 个历史前缀、64 组真实证据评分，25 轮配对计时。概率、gain/lower、support 与规则选择均完全一致。paired 特征版本平均每次评分 CPU 慢 0.430 ms，wall 快 0.195 ms；每 case 两次调用，量级远小于整个前缀成本。Windows CPU 时间量化明显；不将此差异解释为稳定的端到端收益。

每次临时特征 152576 B，新增持久缓存0 B。较早的并发计时保留并注明污染。当前原型没有昂贵的周期结构维护循环，因此本轮没有人为添加一个再宣称优化成功。Sparse Forest 式局部维护仍未实现。

## 3. 本轮结果

### E0 已完成：有内容剂量效应，但不是强成熟度解释

[source-only 完整报告](../outputs/source_dose_main_report/report.md)包含全部行动均值、逐 seed、选择规则、容量与编码漂移。32/32共同前缀、512逻辑/384物理分支全部完成，无运行错误；实际5111808次环境步。

| 关系 | B，全未来均衡，95%描述区间 | 正向 seed | 主条件 B，history=future | 预设判读 |
|---|---|---:|---|---|
| 动力学差异 | +0.001481 [0.000499,0.002412] | 7/8 | +0.001401 [0.000364,0.002486] | 方向为正，未达到预设均值量级；不确定 |
| 奖励冲突 | +0.000937 [0.000491,0.001304] | 7/8 | +0.000893 [0.000145,0.001576] | 不支持预设+0.002的实际量级 |

replace在两个剂量下是完整状态hash相同的复用，因此B恰好等于`平均(R_keep,2048−R_keep,1024)`。它说明较长拟合来源提取的旧候选有小幅保留价值，不能独立证明replace或自动组织有益。也不能用它断言旧知识只训练1024步的整个部署会产生相同结果。

两种关系的Q分别约−0.001726与−0.001733，描述区间均低于0：低剂量时keep/replace的未来日程交互减弱。这是双侧分析结果，不把观察到的负方向改写成预先预测。

frequency仍没有稳定地同时超过keep与replace。新 cohort 也不是所有旧评分规则都没有信号：在old2048、动力学、history=future这一条件，既有lower规则相对keep/replace/mean分别为+0.000739/+0.001558/+0.002285，三个描述区间下端均>0；但相对keep的均值小于0.002，3/8 seed严格正、其余5个为0，且没有跨关系/剂量保持。它是一个局部信号，不能选出这一格便宣称普遍成功或新算法贡献。全部其他条件保留。

全未来均衡的T分别为+0.000247 [−0.000392,+0.000898]和−0.000549 [−0.001376,+0.000246]。主条件和均衡区间均跨0，且在±0.002内，未达到冻结的明确交互判据。没有预注册等效性检验，因此不写成“已证明严格等效”或“任何情境都没有协同”。

**本轮不支持“持久保存会在当前系统中额外放大未来PPO收益”的强猜想。** 两种关系的保存差值在无梯度的自然淘汰/共享先验继承中已经出现；继续PPO没有形成明确的额外增量。这更符合当前机制主要提供继承和重学起点的解释，不能由此把整个研究主题判为错误。

T接近0也不等于PPO没有改变回报。仅为解释该差值之差，直接从同批主条件分支计算PPO−无梯度：动力学replace/none为+0.003652/+0.003633，奖励冲突为+0.002502/+0.003030，四格均8/8 seed正。[逐seed计算与输入hash](../outputs/source_followup_main_report/interpretation_checks.json)明确标为事后解释性检查，不是新增独立主检验；它说明两个保存行动都可从PPO获益，而它们之间的差距没有相应放大。

早期曲线中，前256/512步的replace−none回报差均为0；差异在更晚的自然分槽与继承过程中出现。编码前补偿保持当前有效策略；replace编码后的最大动作概率漂移中位数0.000324、最大0.001097，最大KL为2.806e−6。它仍是“写入＋补偿＋codec”完整行动的效果，不能称为数学上严格相同的编码后policy或纯actor学习效应。无梯度仍有LRU状态变化，不能称为固定策略。

## 5. 证据与创新主张

这些试验能够检验具体因果解释和选择规则的增量，不能证明全领域新颖性。已知任务、切换和组关系是统一给定的控制条件；单 W0、小型导航族、一次存储行动仍是边界。未知情境发现、连续自动组织、容量—经验曲线和跨环境成本优势仍需分别验证。

本轮没有实现新的自动知识组织算法，因此没有验证“在线经验驱动的组织规则已经优于强保存控制”这一核心方法贡献。现有lower在一个条件的局部信号值得独立确认；剂量效应与近零的交互主要帮助排除过强解释，不能顶替该贡献。

## 6. 下一项该验证什么

下面是本轮结果后的方案，尚未执行，不混入本轮结果。

1. **目标改为预测持久内容的继续学习价值，保持问题主线。** 状态应含有限的历史频率、候选拟合步数、最近自然复现的前256/512步恢复曲线、LRU压力和实际维护成本。先比较简单的成熟度＋频率规则、折扣恢复统计与小型线性价值预测器；不要直接增加树层或复杂UCB。它们预测的是未来完整学习回报，不能沿用已失败的短时动作surrogate而只改名字。
2. **自然反馈学习保存规则。** 每个固定长度的决策区间只执行一个保存行动，区间结束归属其实际回报，避免多次写入效果重叠后任意分配信用。未选行动保持缺失；付费observer分叉仅用于研究评估，不返回learner。将少量随机探索与同概率的随机保存基线匹配，失败的写入、验证和探索也计成本。这借鉴METIS的折扣统计，但不继承独立平稳臂的理论保证。
3. **先要求新规则胜过真正较强的保存控制。** 在未见seed、同实际持久包/actor预算、同交互与探索费用下，比较keep、replace、mean、frequency、现有lower、直接共享PPO及同预算独立保留。主要判据是自然淘汰后的重学损失与全流回报；同时记录有益写入漏拒、有害写入误收和计算成本。不能只比较本轮较弱的mean。
4. **把候选形成与保存判断分开。** 本轮9系数父候选由两个来源、三个band平均得到；平均可能丢弃奖励冲突与细粒度控制信息。若规则仍无增量，单独比较平均提取与有界奖励驱动父候选训练，匹配交互/梯度预算；先判断候选是否含有可复用控制信息，再判断存储规则。不能把候选改进全部归于组织器。
5. **结构扩展有条件推进。** 只有重复写入规则产生稳定增量后，再比较扁平库、树或DAG、取消任务/组提示，并引入第二份W0与新环境。当前评分维护成本太小，暂不投入Sparse Forest式事件维护；今后若真实维护成为瓶颈，再以同维护次数随机触发与计算匹配周期方法作对照。

上述方向保持“预训练＋部署后参数学习＋固定持久容量”的目标，但把下一项贡献缩到可证伪的写入规则。树的外形、组件数和局部最好结果都不是通过条件。
