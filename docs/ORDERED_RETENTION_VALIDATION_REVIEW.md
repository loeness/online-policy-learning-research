# 固定规则确认、所选反馈预测与重复写入验证

日期：2026-10-19。范围仍为 C1 的已知任务编号、逻辑组和边界；本轮没有进入未知情境或树/DAG 比较。按顺序分别检验旧规则复现、有限自然反馈的预测价值、完整存储策略的价值。每项按自己的新证据判读。

文献迁移依据为[前一轮全文综述](literature/20261018_SYNTHESIS.md)和[METIS 等方法的适用边界](literature/20261018_decisions.md)：保留折扣反馈和成本核算的思路，把反馈改成真实继续学习之后的所选结果；暂态候选与持久保存分别核算。四动作折扣 ridge 是常规组件，本身不作为创新点。存储操作会改变后续学习状态，因而没有移植固定模型路由的独立臂 regret 保证。

## 1. lower 的独立确认：未通过

[冻结规程](SURROGATE_LOWER_CONFIRMATION_PROTOCOL.md) · [16 种子完整报告](../outputs/lower_confirmation_report/report.md) · [逐种子数据](../outputs/lower_confirmation_report/per_seed.csv) · [独立审计](../outputs/lower_confirmation_audit/main.json)。

固定此前产生局部信号的 dynamics、旧来源 2048 步、新来源 1024 步、history=future 条件，按旧家族 A/B 各八个未使用种子，两种历史共 32 个前缀。lower 只读取各前缀的过去证据。四个真实未来分支用于 observer 评分，结果不训练任何选择器。

| lower 相对对照 | 平均差 reward/step | 分层种子 bootstrap 95% 区间 |
|---|---:|---:|
| keep（主比较） | +0.000050 | [-0.000515, +0.000527] |
| replace | +0.001963 | [+0.001034, +0.002915] |
| mean | +0.002189 | [+0.001303, +0.003045] |
| frequency | -0.000180 | [-0.000722, +0.000333] |

完整机器值以报告 JSON 为准。主比较 3 正、1 负、12 持平，全部 16 个种子进入分母；方向性不确定，未达到原定 +0.002 实际量级。32 次 lower 决策中 28 次 keep、4 次 replace。它高于 replace/mean 不能解释为已经胜过保留旧知识这条简单规则。

非零的逐种子历史均值差分别为 22105 的 +0.001872、22106 的 -0.003581、22112 的 +0.002187、22121 的 +0.000315。一个负例抵消了大部分正向总量；本轮对这四个决策都付费运行了同前缀对照。这支持检查错误写入代价的必要性，但没有为新的安全阈值提供确认依据。

按历史或家族细分的差异仅为描述：本轮不据此重新选种子、删去负例或修改阈值。结论是旧 lower 规则的局部增量没有得到独立确认；后面两项在结果出现前已冻结，检验不同的新假设。

主实验实际 1,966,080 步，128 个未来分支；CPU 2495.281 秒，campaign wall 877.576 秒。pilot 另加 15,360 步。独立审计的 raw rows、动作、状态和容量检查全部通过。

## 2. 所选反馈的保存价值预测

[冻结规程](RETENTION_VALUE_STREAM_PROTOCOL.md) · [实际方法](RETENTION_VALUE_STREAM_METHOD.md) · [配置](../configs/retention_value_stream.json)。

主实验完成，12/12 条流、6 个新种子、每流 64 次决策，合计 768 个所选反馈，无运行失败。[完整报告](../outputs/retention_value_calibration_report/report.md) · [机器结果](../outputs/retention_value_calibration_report/analysis.json)。预测器分别使用六个过去特征和仅常数项，维护同样的四动作折扣统计，只接收真实所选动作的 1536 步后续反馈。不接收第一阶段的分支结果，不在种子之间迁移拟合状态。

主要检验是后 32 次预更新预测的平方误差。负的 linear−intercept MSE 有利于历史特征模型：

| 条件 | MSE 差 | 描述性种子 bootstrap 95% 区间 | 改善种子 |
|---|---:|---:|---:|
| 两种关系等权（主指标） | -3.06199e-6 | [-4.36532e-6, -1.46956e-6] | 5/6 |
| dynamics | +1.37457e-6 | [-0.78845e-6, +3.90851e-6] | 3/6 |
| reward conflict | -7.49855e-6 | [-10.80919e-6, -4.07268e-6] | 6/6 |

总体 MSE 从 5.40478e-5 降为 5.09858e-5，约下降 5.7%；reward conflict 下降约 11.7%，dynamics 上升约 3.1%。这支持“有限过去统计能够帮助部分环境中的所选结果预测”，未支持跨两种关系的一致预测优势，也未检验逐次因果写入收益或策略改进。动作支持数、预测偏差和全部流的结果保留于 JSON/CSV。

本阶段实际 1,216,512 步、4752 次 PPO rollout、76032 次 minibatch update；campaign wall 472.916 秒，计时范围 CPU 1376.031 秒，实际 3 workers。完整持久包峰值 240386 B，两个预测器加固定统计的数值数组合计 1732 B。模型更新 CPU 共 0.109 秒，短操作受时钟粒度影响；该数不包含所有预测/特征计算，也不表示完整组织机制只有这项成本。[主实验独立审计](../outputs/retention_value_calibration_main_audit.json)通过，0 错误、0 警告。

## 3. 重复写入策略

主实验完成，80/80 条流、4 个新种子、两种关系、十方法、每流 48 次决策，无运行失败。[完整报告](../outputs/retention_value_main_report/report.md) · [机器结果](../outputs/retention_value_main_report/analysis.json) · [逐种子数据](../outputs/retention_value_main_report/per_seed.csv)。方法和超参数没有根据第二阶段结果调整。十方法包括 learned_linear、learned_intercept、random、keep、replace、mean、frequency、generalized lower、直接共享 PPO 和独立局部学习。两个学习器的前 16 次均匀探索与后续 epsilon 流匹配；固定规则的探索成本不同，全流指标包含学习器的探索代价。

主比较是 learned_linear−learned_intercept 的完整在线流 reward/step，含 warmup：

| 条件 | 平均差 | 描述性种子 bootstrap 95% 区间 | 正 / 负种子 |
|---|---:|---:|---:|
| dynamics | +0.000210 | [-0.000156, +0.000409] | 3 / 1 |
| reward conflict | +0.000046 | [-0.000350, +0.000562] | 2 / 2 |

两种条件均未得到稳定的方向性增量，未达到 +0.002 的预设实际量级；去掉 warmup 也不改变判读。每种关系仅 4 个种子，区间是探索性描述，不是高精度总体估计。不能把第二阶段的预测误差下降解释为第三阶段的策略改进。

learned_linear 相对 replace 在两种关系中分别为 -0.002620、-0.002442，相对 generalized lower 为 -0.001322、-0.001508，相对直接共享 PPO 为 -0.042120、-0.010262：这些比较各自四个种子全部为负。相对独立局部学习，dynamics 为 +0.001633，reward conflict 为 +0.000632，后者区间跨零。完整多重对照均为辅助描述，不据此重新挑选成功判据。

自然复现的最初 256 步回报也没有显示 learned_linear 优于 learned_intercept：两种关系等权、八条流平均分别为 -0.007889 和 -0.007842。replace 为 -0.004738，直接共享 PPO 为 +0.004903。这里不同方法已经经历各自过去的操作和训练，只能称事实复现表现，不能称因果恢复损失或单次写入收益。

本阶段实际 6,144,000 步、24000 次 PPO rollout、384000 次 minibatch update、3072 次离散选择反馈、1847 次父模块写入和 7920 次局部淘汰。所有方法环境步数和 PPO 更新数匹配。campaign wall 1059.754 秒，总 CPU 5936.000 秒，实际六进程；完整持久包峰值 240322 B，小于 262144 B。learned_linear 八条流 CPU 为 599.563 秒，learned_intercept 为 598.969 秒，直接共享 PPO 为 585.125 秒；本轮没有观察到学习型规则带来的总 CPU 节省。模型更新 CPU 0.281 秒及序列化 CPU 28.297 秒分别记录；短操作受计时粒度限制。

[全流回报图](../outputs/ordered_retention_figures/s3_comparison_whole_stream.png)和[逐块轨迹](../outputs/ordered_retention_figures/s3_comparison_block_returns.png)保留完整结果。直接共享 PPO 在这套共同 harness 中明显更强，当前离散组织方法尚未提供超越它的理由。该比较是受控算法对照，不是外部标准基准上的 SOTA 比较。[主实验独立审计](../outputs/retention_value_comparison_main_audit.json)通过，80/80 条流、0 错误、0 警告；八个关系/种子配对的共同探索前缀完全一致，所选反馈重放、actor/checkpoint、容量和协议哈希检查均通过。

## 4. 本轮判读与下一项待检验问题

三项假设分别得到：**旧 lower 增量未独立确认；所选反馈预测获得条件性支持；学习型重复写入未获得策略增量支持。** 全部 pilot 与 main 共新增 9,443,328 次实际环境交互。最后一项否定的是本轮具体的特征、预测目标、四动作和候选构造组合，不能据此证明有限容量的在线知识组织问题不可行；它也不构成该问题的核心算法创新已经实现的证据。

下一步应先定位「预测改善为何没有改善决策」，保持当前数据流和强对照，暂不增加树/DAG 或隐藏任务边界。以下是待检验解释，并非本轮已经证明的原因：

1. **特征主要描述学习状态，未充分描述操作差异。** 频率、年龄、拟合量可能预测下个块的难度，却无法区分两个候选在相同控制情境下的行为差异。下一版可增加有界历史探针上的候选与当前策略动作分布差、优势方向一致性；探针、计算和证据均计费。先检查它能否预测操作间差异，再替代当前选择器。
2. **事实结果预测不等于动作增量预测。** 随机探索中的总体 MSE 下降可能来自跨状态的共同回报变化，未改善 keep/replace 的排序。可先用独立随机流估计已知随机选择概率下、相对 keep 的条件增量和排序，使用交叉拟合并报告有效样本量；由于操作改变后续状态，这仍只识别给定行为策略分布与三 bout 时域的局部效果，不自动产生长期保证。若需要共同前缀分支诊断，必须单独计入交互成本，且不能把分支标签免费喂给部署器。
3. **当前候选构造可能弱于直接梯度写入。** 把两个局部有效策略取平均后进行离散写入，与持续训练共享参数存在算法差异；本轮无法把性能差距单独归因为选择器。应在同一个候选内容/共享更新器下比较保留规则，或先让候选来源达到直接共享 PPO 的学习质量，再判断组织规则是否还有独立增量。

下一次实验应只选其中一个可归因的修改，并保留当前失败方法作为基线；本轮没有根据结果重调配置或追加筛选种子。

## 5. 实现和证据边界

- 新的 keep 保留当前父模块及绑定关系，支持多轮组间替换；不能继续使用旧单次实验中固定 group 0 的 keep。真实写入补偿当前局部参数，并记录量化漂移。
- 只有一个当前候选，从两个当前驻留代际形成；没有历史候选库。完整包计入两个预测器、六任务统计、八 bout 窗口、选择 RNG 和一条进行中的反馈记录。原始日志是选择器不可访问的实验记录。
- 继承的 PPO 每 256 行清除 actor Adam 动量；actor 参数继续学习，critic 状态与全局更新计数继续。该实现适用于全部对照；不是未经修改的外部 PPO/SOTA 复现。
- calibration pilot 使用 9216 步；十方法 comparison pilot 使用 92160 步，均无运行失败。窄预检查对 11 条流逐次重放预测与所选模型更新，末状态完全一致，两个学习器的共同随机探索轨迹 SHA 相同；[检查记录](../outputs/retention_value_pilot_preflight.json)。这些 pilot 只验证流程。
- 独立完整审计也通过：[calibration pilot](../outputs/retention_value_calibration_pilot_audit.json)、[comparison pilot](../outputs/retention_value_comparison_pilot_audit.json)。它进一步重放特征、选择 RNG、所选更新和复现统计，核对 actor/checkpoint、进行中状态、原始奖励和 PPO 更新；说明文档差异等警告保留。额外的暂态序列化估计不等于 Python 进程 RAM 的实测上界，也不能把 snapshot 边界计费称为任意步精确恢复。
- comparison pilot 最后期间追加了上述 optimizer 纯文档说明：九条流保存旧协议，一条保存新增说明；旧 runner 的结束汇总重新读取协议哈希，因而 root/frozen-start 哈希也不同。原数据与各自 snapshot 保留，报告标记该 provenance 限制；没有改算法、特征、参数、数据流或判据。主实验前 runner 已改为复用开始时冻结的哈希。
- 旧 pilot 的 `totals.wall_s` 是各流 wall 的和，不是 campaign elapsed。新 main 增加独立的 campaign wall、父子 CPU 及实际 worker 数，串行路径避免双计。Windows process CPU 量化可能把很短的单次模型更新记为零；不据此宣称没有计算成本。
- 运行前复核修正了更新后 sidecar actor 过期、lower 通用绑定、keep 无操作语义、失败半 bout 回报核算和进行中记录计费。均在主实验前处理；不把这些软件修复写成科研收益。

树/DAG、无编号辨识、每次写入的有益/有害因果标签和安全保证均未在本轮实现。任务编号、逻辑组和切换边界仍是给定的；比较流使用固定的八块交替周期，四个比较种子都具有相同起始相位。本轮也没有检验不同结构或最优容量分配：独立对照保留了相同的 89 B actor 布局，共同的完整包上限并不意味着各方法实际字节完全相等，更不意味着获得完整容量—性能 Pareto 优势。
