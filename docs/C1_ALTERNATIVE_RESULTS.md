# C1 alternative methods report

The saved-data report is generated by `scripts/report_c1_alternatives.py`. It reads result JSON, frozen validation selections, and the preexisting Step 2 tree selection. It starts no runner and performs no training. After the alternative suite finishes, run:

```powershell
.venv\Scripts\python.exe scripts\report_c1_alternatives.py
```

The report refuses to write outputs unless it finds exactly 18 formal result files and 15 validation result files in the declared alternative cohorts. Failed result files count toward these inventories and remain listed; only complete formal rows enter performance averages. It also checks each saved validation score against the declared weighted score and keeps every candidate in the CSV.

## Declared comparisons

The formal cohort uses seeds 181, 193, and 211 for six methods:

| Method | Cohort and capacity |
| --- | --- |
| Frozen Step 2 tree reference | Low compressed tier; existing tree selection; original adaptive and complete-agent caps |
| `tensor_learned` | Low compressed tier; W0-derived shared source basis is trainable |
| `output_mixer` | Low compressed tier; W0-derived shared source basis is frozen |
| `hierarchical_output_mixer` | Low compressed tier; frozen basis with fixed-family coefficients |
| `full_context_head` | Full shared actor plus six compact heads; measured outside original adaptive caps |
| `full_context_head + EWC` | Same full actor and heads with task-free diagonal empirical-Fisher EWC; measured outside original adaptive caps |

Tensor candidates use validation seed 919. The context-head learning-rate candidates and EWC coefficients use seed 923. EWC validation reuses the selected ordinary context-head learning rate. The tree reference uses the saved Step 2 selection and is not retuned here. The full context-head methods must fit the declared 393,216-byte complete-agent cap. Their trainable actor, critic, heads, optimizer, continual state, router, explicit mask, and rollout are accounted for; they are Pareto references outside the 15,952-byte / 30,700-byte original adaptive caps.

All six arms share one trained source checkpoint W0. Formal seeds 181, 193, and 211 vary deployment runs only; they do not vary pretraining. The common C1 runner supplies endpoint IDs and phase schedule during seen, held-out, and revisit oracle phases. Endpoint IDs and switch cues are hidden only during later history continuation. That history stage uses the calibrated transition bank and fixed family structure supplied by this C1 setup; the bank is frozen during the hidden stream. Thus unknown boundaries occur in history continuation, but this does not test from-zero latent-context discovery or dynamic family structure. The full shared actor uses the supplement amendment's 3 × 64 visible-band input bias.

The optional source-retention probe is filtered to the alternative cohorts and seeds 181, 193, and 211. It forces root route 0 for a 512-step NavigationEnv diagnostic with no updates and compares each policy with the pristine W0 for the same seed. This measures source-task behavior; it is not a router-accuracy or routing test.

The tensor methods store a 195-float (780-byte) W0-derived action contrast basis. The output mixers store it as a frozen residual with no Adam moments; the learned tensor has optimizer state for its trainable basis. Adaptive-byte comparisons exclude the endpoint seen mask; complete-agent accounting retains the mask and all serialized/live deployment state. Adam tensor accounting includes scalar per-parameter step state.

## Interpretation limits

The source basis spans action-row permutations in the contrast space. This aligns with the synthetic action-remapping family and does not establish general transfer beyond the W0 source row space. A full actor comparison also has a larger parameter and memory budget than the low-tier methods. Results are finite-seed C1 evidence, not a SOTA ranking or a causal claim about freezing.

These runs do not establish discovery of unknown context boundaries, dynamic family structure, or knowledge replacement after the memory cap is full. They use one declared W0 construction per matched seed cohort. The EWC control is the task-free diagonal empirical-Fisher adaptation in this protocol; the context-head experiment is not a reproduction of a published continual-learning benchmark method.

## Observed saved results

All 18 formal runs and all 15 validation runs completed. The formal summary uses three seeds; SD is the sample standard deviation. “All six ≥ 80%” counts runs meeting the threshold on every final context.

| Method | Final success, mean ± SD | All six ≥ 80% | Immediate old-task positive drop | Hidden-stream success | Adaptive bytes, mask excluded | Peak complete bytes / cap |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Tree reference | 100.0% ± 0.0 pp | 3 / 3 | 0.03 pp | 100.0% | 15,952 | 170,822 / 188,416 |
| `tensor_learned` | 100.0% ± 0.0 pp | 3 / 3 | 0.25 pp | 99.9% | 4,312 | 149,231 / 188,416 |
| `output_mixer` | 95.7% ± 7.5 pp | 2 / 3 | 0.00 pp | 99.3% | 2,748 | 146,936 / 188,416 |
| `hierarchical_output_mixer` | 100.0% ± 0.0 pp | 3 / 3 | 0.00 pp | 99.9% | 2,972 | 149,408 / 188,416 |
| Full context head | 96.1% ± 5.6 pp | 2 / 3 | 0.00 pp | 97.5% | 105,968 | 236,589 / 393,216 |
| Full context head + EWC | 80.6% ± 13.2 pp | 0 / 3 | 1.32 pp | 90.8% | 105,968 | 316,003 / 393,216 |

The flat `output_mixer` retained 100% on five of six contexts for all seeds, but seed 193 finished at 22.2% on A0 (87.0% mean across its six contexts). The full context head's seed 181 finished at 50.0% on A2; its other two seeds met the all-six threshold. The EWC full-actor control missed the all-six threshold on all three seeds. These outcomes remain visible rather than being averaged away.

Validation selected `tensor_learned` at LR 0.003 / entropy 0.06 (score 0.9406), `output_mixer` at LR 0.01 / entropy 0.06 (0.6634), `hierarchical_output_mixer` at LR 0.003 / entropy 0.06 (1.0000), the full context head at LR 0.003 / entropy 0.06 (0.8838), and EWC coefficient 10 at that same context-head LR (0.6949). The tree reference reused its frozen Step 2 selection.

In the optional root-route-0 source probe, all three compressed methods and the tree reference matched their same-seed pristine W0 source return and success exactly (0 mean gain). The full context head averaged −165.17 return and −35.49 percentage points of source success versus same-seed W0; the EWC full actor averaged −109.00 return and −3.71 points. This is a forced-route source-task diagnostic, not a router evaluation. The alternative subset adds 10,752 such evaluation interactions (18 trained checkpoints and three matching W0 controls).

The strong compressed results are bounded to the fixed source-basis action-remapping prior. The full actor is a larger adaptive-state reference, and EWC did not improve this full-head comparison under the selected settings. These observations do not isolate the causal effect of freezing or establish general transfer.

## Generated artifacts

When the complete saved inventory is available, the report generator writes:

- `outputs/c1_supplement/alternative_analysis.json` — source selections, every run row, failure inventory, and formal summaries.
- `outputs/c1_supplement/alternative_results.md` — human-readable results and interpretation.
- `outputs/c1_supplement/alternative_summary.csv` — every formal run and validation candidate, with per-context scores and capacity, optimizer, CPU, and interaction accounting.
- `outputs/c1_supplement/alternative_comparisons.png` and `.pdf` — six-method plot with three seed points per method and mean markers.
- `outputs/c1_supplement/source_retention.json` — when present, same-seed W0 source-retention rows for the new cohorts; the alternative report joins only seeds 181, 193, and 211.
