2026-10-16，pilot完成、formal运行期间只读检查；没有改动正在使用的训练源文件。

未发现使pilot训练指标失效的问题。检查覆盖槽淘汰、本地参数及Adam清理、共享保留、generation、active/frozen的前缀一致、成对评估、actor和W0＋checkpoint的实际字节计量。

有两项解释需要精确限定：

1. 正式bout为4,096步，而周期checkpoint每1,024步保存。它可以恢复智能体参数、优化器、缓存与RNG，**缺少环境位置、当前观测、部分episode累计值和执行日程位置，不能从该点精确续跑原始轨迹**。冻结版本把周期保存也称为stage-end state，这个名称不准确。阶段终点和周期保存都只作智能体状态恢复与评估用途。
2. 256 KiB指一个智能体checkpoint加共同W0文件。源码快照、外生实验日程、研究日志和历史checkpoint属于复现归档，单独存储，不是部署学习器可检索的经验库。该预算不是整个Git仓库或运行期RAM限制。

原执行源码和协议快照保留上述措辞；本复核修正其解释。后续不得把这些保存文件描述为任意时点精确续训能力。
