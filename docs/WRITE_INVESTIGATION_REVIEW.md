# 在线共享写入研究：本轮结果与判断

## 结论

本轮已完成预定的受控写入、容量耗尽、未知情境和跨生成器检查，并增加完整利用新数据的独立基线。**当前共享写入与父模块重组规则尚未证明优于简单奖励感知共享或较强的独立在线学习。**研究问题仍成立；当前算法需要修改，不能把这些结果称为核心创新已获验证、SOTA 或可投稿充分证据。

冻结选择、所有候选、负结果、失败、中断、实际文件字节和交互成本均保留。汇总单位是 seed；本轮多数正式对照 3 个 seed，跨底座各 2 个部署 seed，只作描述性比较。

## 1. 受控路由：共享有作用，收益 gate 未胜简单规则

在新正式种子上，训练流每步奖励均值：

| 条件 | 在线训练 R / step |
|---|---:|
| 独立局部更新 | 0.014793 |
| 仅动力学分组共享 | 0.015188 |
| 动力学 + 奖励分组共享 | **0.019149** |
| 验证集选出的放宽 gate | 0.018754 |
| 验证集选出的投影 gate | 0.015320 |
| 相同试用更新全部退回局部 | 0.014815 |

放宽 gate 对“全部退回局部”在三个 seed 都更好，差值分别为 +0.006702、+0.001923、+0.003192。因此该受控设置中的效果不能全部解释为局部在线参数学习。与此同时，放宽 gate 的平均表现低于更简单的奖励感知共享，不能说明复杂写入决策产生了独立优势。

这里的指标是训练流奖励，不含探测。后面的完整交互预算对照使用另一种明确标注的全流口径，不混合两种分母。

## 2. 固定容量与未知情境：较强独立基线领先

以下均为全流奖励：训练与探测的奖励总和，除以训练与探测交互总数，评估交互另计。

| 测试 | 放宽 gate | 奖励感知共享 | 完整利用新数据的独立基线 |
|---|---:|---:|---:|
| 已知局部编号、未知共享分组，3 seeds | 0.006329 | 0.006081 | **0.007487** |
| 无编号、无切换提示，3 seeds | 0.005722 | 0.005546 | **0.008187** |
| detour + 独立预训练底座 17，2 seeds | 0.001504 | 0.000948 | **0.001843** |
| detour + 独立预训练底座 29，2 seeds | 0.001185 | 0.000856 | **0.001890** |

完整数据利用基线使用相同路由思想、7 个独立小修正、0.004 局部学习率，并将第四个 rollout 也用于训练，取消 uniform probe。它匹配总训练加探测交互：known 每 run 51456，unknown 每 run 49152。每段停留时间、PPO 更新数和计算并不相同，不能解释为全部资源严格匹配。

detour 底座 17 中，放宽 gate 原本略高于旧的留出数据独立基线（0.001504 vs 0.001338）；增加完整数据利用对照后，该优势没有保持。这个补充发生在看到该小幅结果后，已单独登记；没有据此调整候选或阈值。底座 29 单独报告，没有把两个底座的部署种子池化成四个独立预训练种子。

unknown 中，放宽 gate 与完整数据利用基线的正任务训练成功率分别约 13.2% 与 21.6%，终点正任务成功率约 18.1% 与 26.4%。奖励差异也伴随任务完成质量差异。终点每任务仅 4 个评估回合，不应过度解读其精确数值。

## 3. 父模块重组：结构覆盖改善，策略质量下降

两条件、两验证 seed 共实际执行 26 次回收，detach 24 个局部槽、join 50 个局部槽。两种方法都保留相同的固定维度累计证据，因此对照隔离的是是否允许父模块重组。

| 条件 | 固定父模块：未分组训练比例 | 重组：未分组训练比例 | 重组 − 固定的训练 R / step |
|---|---:|---:|---:|
| 奖励感知共享 | 68.75% | 47.92% | −0.000748 |
| 放宽 gate | 68.75% | 52.08% | −0.000651 |

结构操作确实发生；负结果并非“没有触发重组”。更多经验进入共享组仍未换来更好的奖励。按预登记的正均值增益准入规则，本候选的正式及 unknown 扩展被跳过，不算 pending，也没有虚构相关样本。

当前 LRU 重组只保证编码前驻留策略即时等价，不评价被替换知识未来的价值。新父模块从零开始，旧共享知识被移回局部；一旦这些局部随后被逐出，知识仍可能丢失。这是合理的失败解释，尚不是被独立消融证实的因果结论。

## 4. 可靠性与成本

23 个独立观察者候选诊断使用了额外 42714 次环境交互。8 个配对回合的小样本中出现一例“接受但旧情境变差”和一例“拒绝但候选有益”。这说明 surrogate 的判断仍有缺口；不能据此估计经校准的错误率或声称安全性。

共享方法 actor 编码为 230 B，独立 7 槽为 236 B。完整包包含 W0、优化器、路由和证据，所有本轮完成的流式 cohort 均满足 256 KiB 上限，并通过重新生成的物理文件与交互账本审计。同上限并非实际包字节完全相等；这也不是只约束总存储、任意分配 actor/证据容量时的最优比较。

本轮 write 账本包含 **16 个完成 cohort、100 个完成运行**（含验证与 pilot），另保留失败和中断成本。已汇总完成实验和独立评估 4690797 次交互；加上失败的精确成本与中断下界，至少 **5278326** 次。该数是本轮账本，不是全仓历次研究的总量，也不包含单元测试的模拟步骤。

有界历史增量统计的微基准约 36 倍加速是组件优化，不是策略算法整体加速。完整数据利用基线在 known 中平均 CPU 秒约 56.67，放宽 gate 约 67.26；unknown 则约 67.02 vs 70.99。CPU 为每 run 进程成本的 seed 均值，不能当作整批实验的 elapsed makespan，也没有整体计算优势结论。

## 5. 实现及审计修复

- 初始验证发现 AnchorBank 代数字段错误，以及未见过终止特征被误判为奖励冲突；失败 cohort 保留，修改后从新目录完整验证和选择。
- unknown 中断仅重跑未完成单元，已完成单元保留。聚合 summary 曾缺少三个协议字段；从已核验的 frozen config 透明补齐，原 summary 字节和修复前报告保留。12 个 run 的数据与 source snapshots 未改。
- 完整数据利用基线发现训练后 SB3 缓存的非叶 autograd 张量无法直接 deepcopy；清除复制时的临时动作分布缓存并恢复原对象，参数不变。失败的 154368 个训练步骤完整计费；回归测试和独立 pilot 通过后重跑。
- 受控正式 cohort 有一个 run 的协议文档副本包含额外的后选因果对照段落。所有代码/配置一致、各 run 快照有效，但 strict 全 source 同一性不是 clean pass。`PROVENANCE_NOTE.json` 保留此项；不重写历史快照掩盖差异。

最新流式审计在 `outputs/write_current_reports/index.json`，13 个完整流式 cohort 均通过。它不覆盖或消除上一项受控正式 cohort 的文档差异。

## 6. 下一轮应验证什么

优先项是提高写入决策的价值和数据效率，而非增加结构复杂度：

1. 检验“先评分、再局部训练 holdout”的时间顺序，争取利用全部新数据，同时保留共享候选在评分前未接触该数据的条件。
2. 以驻留局部知识初始化公共分量，避免回收后从零重学；必须测复现收益、实际容量或同预算性能，不能把代数重参数化当作知识压缩证据。
3. 把冷继承、共享更新和父模块替换统一纳入收益证据，补上当前 `cold_prior_binding` 未经 gate 的缺口。
4. 用自然复现的收益及遗忘成本研究保留规则，和 LRU/LFU 比较；保留稀少但重要的情境，不能只增加分组覆盖。

这几项尚未在本轮实现，不计作成果。具体接口与假设见 [方法说明](WRITE_INVESTIGATION_METHOD.md)。它们应在新验证种子中分别消融，再进入独立正式评测。
