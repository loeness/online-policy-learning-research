# 共同研究背景与当前范围

本仓库保存“预训练初始化 + 部署后持续在线策略学习”的研究记录。初始策略不是最终策略；环境交互形成的经验需要进入可长期保留的策略修正，并与已有知识共同决定之后的行为。

## 固定研究问题

智能体不应依赖公开任务编号或切换通知，最终希望通过有限历史发现潜在情境，把经验整理成有共享关系的策略知识，在严格持久容量下持续改进。表示的基本形式为

\[
\theta_t=\theta_0+\sum_{v\in P_t}\Delta\theta_v.
\]

树表达共享与特化的关系。它不是研究终点，也不是为每个环境永久保存完整策略的数据库。长期目标包括创建、拆分、提升、合并、压缩和替换，但当前实现必须与这些目标分开说明。

需要独立处理情境识别可靠性和策略改进可靠性。识别相似并不证明修正有益；回退还要保留获取新信息的探索。在线交互、学习步数、永久状态、临时历史、优化器和工作区都要核算。

## 截止本次快照，已经执行

- A：固定源数据获得初始策略后，真实仿真反馈进行全参数 PPO 或小残差更新。
- B：未知旋转与切换下的历史路由、参数保留和重访；实现错误的初轮和修正后的独立复验均保存。
- B+：策略参数/近期历史/优化器隔离，真实 checkpoint 恢复，强解析 history-only 对照。
- 压缩：Top-K 直接压缩失败、固定比例追加在线修复，以及九种节点内表示/压缩的统一对照。
- C1：固定父子结构、两档容量、扁平/树/非层级字典对照；父修正由在线奖励学习，并检验留出变体迁移。后续隐藏标签续训使用此前有标签校准的原型。
