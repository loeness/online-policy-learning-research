# 在线经验如何形成有界策略知识：文献边界与候选算法

日期：2026-10-15。本文是文献核查与研究设计，不是新实验结果；没有启动 C2/C3。共同主题保持为预训练初始化后，在真实部署交互中持续更新持久策略知识，控制交互、计算、遗忘和实际存储。

## 1. 修正当前贡献定位

C1 验证了小型持久修正和给定家族下的共享机制。这些应作为下一阶段的可行性基础，不足以独立构成论文的核心新意。上轮 81.4% 的修正状态节省主要来自共享源输出基的表示变化，并不是自动经验整合的结果。相同源输出基下，加入家族参数从 2,748 B 增至 2,972 B，改善了性能，但没有直接减少字节。

真正要研究的对象是：在线经验应该写到哪里，何时共享或特化，以及容量满时如何重新组织可复用知识。树是结构假设之一。以下文献比较不构成“所有已有工作均未解决”的新颖性证明。

## 2. 已有工作的实际重叠

| 工作 | 已有机制 | 对本研究的边界与用途 |
| --- | --- | --- |
| [TreeLoRA, ICML 2025](https://arxiv.org/abs/2506.10355) | 梯度相关统计、bandit 分支选择、共享/特化适配器树、增量增长及溢出时合并。 | 最接近的结构先例。训练按明确任务和标注数据组织，任务末更新树；测试不需任务身份不等于训练无任务边界。不能把树增长、梯度相似性或 overflow merge 单独当创新。 |
| [HOP, 2024](https://arxiv.org/abs/2411.03008) | 用成功轨迹状态的相似性激活历史 checkpoint，并组合策略输出。 | 接近无标签路由；保存完整策略及可信状态，结构偏历史 checkpoint 链。其原文未给出全局字节上限与共享修正的结构整合机制。 |
| [CST, NeurIPS 2010](https://papers.nips.cc/paper_files/paper/2010/hash/27ed0fb950b856b06e1273989422e7d3-Abstract.html) | 把示范轨迹分段成技能链，再合并为技能树。 | 已有“分段＋合并可复用技能”。对象为时序 option/子目标，输入为解题示范；不同于部署后的共享参数修正归属。 |
| [Continuous U-Tree, AAAI 1998](https://www.cs.cmu.edu/~mmv/papers/will-aaai98.pdf) | 依据奖励/价值差异细分状态区域，形成抽象 MDP。 | 拆分应服务于决策与价值预测，可借鉴；树划分的是状态，不是策略参数共享关系。 |
| [Progress & Compress, ICML 2018](https://arxiv.org/abs/1805.06370) | 固定大小 active column 和知识库、蒸馏、online EWC 与遗忘。 | 双时间尺度、固定参数规模、知识整合都已有先例。原框架仍需要识别任务边界，未决定细粒度修正的共享归属。 |
| [TAPD, 2024](https://arxiv.org/abs/2411.16532) | 在无外部目标的探索预训练阶段周期性蒸馏，再迁移到下游任务。 | 无边界结果应限定其探索阶段；下游仍采用按任务进行的 progress/compress，不能泛化成所有部署学习均无需边界。 |
| [Modular Lifelong RL, ICLR 2022](https://arxiv.org/abs/2207.00429) | 可复用神经组件的组合学习，并用 replay 的离线 RL 保持旧任务。 | 组合式终身 RL 已有强先例；应比较结构学习方式、任务信息、回放和模块数是否随任务增长。 |
| [Dirichlet-process task mixture, 2022](https://arxiv.org/abs/2205.10787) | 无明确任务边界的概率任务归属与按需新增组件。 | 借鉴情境后验和 novelty proposal；原方法动态扩展容量，不能直接满足固定持久字节约束。 |
| [3RL, CoLLAs 2023](https://arxiv.org/abs/2205.14495) | 循环状态和经验回放驱动的 task-agnostic 在线学习。 | 必须考虑的无树强对照；其 v1 使用 In Praise of a Simple Baseline 标题，当前 v3 为 Gaining Insights and Overcoming Challenges。 |

其他相关机制：[Learn to Grow](https://arxiv.org/abs/1904.00310) 已把结构优化与参数学习分开；[Lifelong Learning of Compositional Structures](https://arxiv.org/abs/2007.07732) 已区分组合已有组件与适应组件。因此，“复用/修改/新增”或者“先组合、再整合”本身也不是充分的新贡献。

## 3. 首先区分两种关系

**情境识别关系**回答“当前是什么生成过程/控制情境”；**策略修正兼容关系**回答“同一个修正能否帮助这些情境”。两者不应强制相同。

观测相近的情境可能需要冲突动作；观测不同的情境可能复用同一个执行器修正。奖励目标与历史都要进入识别。转移模型 novelty 是建分支的候选信号，不能单独证明需要新的策略参数。没有尝试过的动作也会产生预测不确定性，不应被立即判作环境变化。

可用短历史和简单概率/循环模型估计情境后验；另用跨情境策略改进证据判断共享。识别树与知识共享结构可以不同。最初不需要实现两套复杂网络，保留两套统计与决策标准即可。

## 4. 五个问题的一致候选解法

### 4.1 经验先写哪里

第一版采用保守默认：新知识先写当前局部修正，暂不让单一情境的梯度直接改变全部父节点。已验证的共享修正在较慢整合周期中更新。未知情境使用预算内预留的一个试用槽继续学习，同时获取识别信息；不能因不确定而永久冻结，也不能让试用槽无限增加。

共享方向可由多个情境的梯度提出，[PCGrad](https://arxiv.org/abs/2001.06782) 或 [MGDA](https://arxiv.org/abs/1810.04650) 可作已知优化工具。例如一阶候选可寻找范数受限下使各情境梯度内积尽量非负的方向。它只是局部近似：梯度受到访问分布、行为策略、坐标尺度和 critic 误差影响。梯度对齐不证明真实回报均提高。

### 4.2 何时提升为父知识

在同一参数坐标内提出共同修正 d，再重写旧叶修正为 delta_i-d。需要同时检验：它对多个情境是否有用，稀有情境是否退化，能否降低残差 rank/精度/支持集或删除冗余模块，以及新情境是否更易适应。

如果原来两个叶各占 N 个数，提升后新增 N 个数的父节点、两个叶仍各占 N 个数，则从 2N 变成 3N。即使所有旧策略完全不变，也没有压缩。只有实际编码成本减少，或者同预算下策略质量提高，才是有效整合。

当前自由系数形式还存在不可识别性：C_g 加 D、同族所有叶的 A_i,b 减 D，会保持所有叶的组合策略不变，却改变父节点回退和未见情境初始化。因此仅凭训练后参数，不能认定父节点就是“通用知识”。可以增加明确的分解约束，并使用留出情境迁移和模块消融检验，但不能把某一种坐标规范当作泛化证明。

### 4.3 何时创建、拆分、合并、删除

| 操作 | 候选触发 | 接受依据 |
| --- | --- | --- |
| 创建 | 持续无法被现有模型解释，且旧修正不能改善决策 | 试用修正确有收益，能在预算内保留 |
| 拆分 | 同一组内部反复出现相互冲突的改进需求 | 拆分后的决策损失下降超过新增容量与训练成本 |
| 合并/提升 | 多个局部修正存在兼容的共同部分 | 整合后性能保持在容差内，实际字节减少或同预算表现提高 |
| 删除/替换 | 知识可被其他模块替代，或未来价值低于替代项 | 删除反事实损失、预期复现与再学习成本支持该决策 |

事件异常不立即触发新分支；观测相似不立即合并；一次低回报不立即删除。应有最小证据量、操作间隔和拟合/检验数据分离，以免围绕噪声反复生长和合并。

### 4.4 容量满后保留什么

历史平均回报不能直接充当节点价值：容易的情境可能不需要专用知识，罕见但难再学习的知识可能更值得保留。复现频率是需求线索，还要结合删除后的损失、再学习交互数和节点服务的其他情境。

一种可研究的近似是按“预计复现概率 ×（删除损失＋再学习代价）/ 可释放字节”提出淘汰候选，再检查模块间互补关系。它不是已证明的最优规则。父节点价值要覆盖其所有使用者，不能只统计该节点被单独路由到的次数。

容量操作也可先清掉不活跃模块的 Adam 状态而保留策略系数；这不改变当前推理策略，却会影响再次学习速度。该动作应与删除知识分开比较，不能把优化器释放当成策略知识提炼。

### 4.5 两种可靠性与继续探索

情境后验可靠不等于策略修正可靠。前者检查历史证据与预测，后者检查相对父策略/基础策略的改进证据。识别可靠但修正证据不足时可先使用父策略、继续训练局部候选；修正曾有效但当前归属不明时，不能直接调用该叶。

[SPIBB](https://arxiv.org/abs/1712.06924) 提供了在数据不足的状态动作处保留基线行为的有用思路，但它的原始保证属于特定 batch-RL 假设，不能直接移植成未知非平稳神经 RL 的保证。未知动作仍需要有预算的信息采集/探索；基线本身也未必适合新环境。

## 5. 一个统一但尚未验证的结构选择准则

对候选结构操作 a，设 K 为当前完整持久知识状态，可研究：

S(a) = LCB[Delta J(a)] + lambda * [bytes(K)-bytes(K^a)] - eta * compute(a).

另要求 bytes(K^a) <= B，并对受影响旧情境设置可容忍退化约束。这里 J 的情境权重应包含预计复现与稀有情境风险；LCB 必须说明统计假设、覆盖和校准方式。实际字节要包含 router/prototype、模块连接、优化器、Fisher、replay 等。整合计算、候选验证交互与临时工作区也要计量，不能当作免费离线过程。

这可视作决策损失与表示成本的折中。[Rate-distortion RL](https://proceedings.mlr.press/v139/arumugam21a.html) 给出信息与策略次优性的理论视角，但互信息量不是神经网络文件字节，原论文的 regret 结论不能直接用于本实现。此处 S 是候选设计框架，单写一个加权目标并不构成算法新颖性或理论保证。

最难的是 Delta J 的可信估计：同一真实时刻看不到没执行动作的奖励。候选可用有行为概率记录和支持条件的 OPE 作筛选；重要性权重失控、有效样本量不足、旧数据过时则应拒绝强结论。需要真实交互检验时必须计入预算。对训练数据拟合后再在同一数据证明提升、反复挑选同一验证集、或把 critic/ensemble 方差直接当严格置信界都不充分。

## 6. 树以外的结构

| 结构 | 优点 | 局限与适用条件 |
| --- | --- | --- |
| 自适应树 | 共享到特化清楚，父级回退简单，操作局部 | 情境的共享关系须接近嵌套；交叉因素可能迫使复制 |
| 有界模块字典＋稀疏关联 | 一个情境组合少量模块，便于检验交叉复用 | 路由系数、关联边和情境描述也占容量；组合不必然可加 |
| 根式 DAG | 一个知识模块可服务多个分支 | 更新影响范围更广；祖先经多条路径出现时必须去重，不能重复求和 |
| MDL / rate-distortion 结构选择 | 统一考虑损失与实际编码成本 | 不是另一种数据结构，也不自动提供可靠价值估计 |
| 截断概率混合 | 自然表达旧情境/新情境的不确定性 | 未截断的 CRP 会无限增长；必须加入真实容量约束与压缩/替换 |

例子：室内/室外 × 地毯/硬地。先按室内外分树，会把地毯修正复制到两支；按地面分树，会把光照相关知识复制到两支。稀疏模块图可分别复用因素，再保存确有必要的交互残差。这些名称只是解释，不是给算法的标签；能否从历史识别和组合要通过实验检验。

第一版建议保留同一模块接口：先实现可变分组、局部学习、共享整合和严格预算，再比较树约束与扁平稀疏关联。若交叉因素确实成为瓶颈，再增加 DAG；不预先把深树当作最终答案。

## 7. 怎样使贡献可被证伪

1. 三类流：真正嵌套的共享关系；交叉因素重组；观测相似但控制需求冲突。加入复现频率不均、随机切换、逐渐漂移、噪声和需要主动探测的未知动作。避免只用可被简单动作逆映射解决的环境。
2. 所有主方法训练时无任务标签或切换提示。真值仅用于评价和明确标为 privileged 的诊断。先让结构方法共用路由器，隔离结构作用；再研究联合学习。
3. 对照至少包括：有界循环 replay / 3RL-style；周期 P&C-style 整合；TreeLoRA-style 梯度树和近邻合并的 RL 改编；同预算扁平模块库；树；稀疏关联/DAG。改编版要写清楚，不能称原论文 SOTA 忠实复现。
4. 消融：仅相似性或梯度驱动共享；去掉整合；固定结构；去掉改进可靠性；只按复现次数淘汰；去掉容量约束作为非部署上界。共享更新必须检查不活跃旧情境。
5. 每次结构变化记录：实际释放字节、即时各情境损失、整合计算、额外交互、候选接受/拒绝和之后重访恢复。除最终回报外，绘制经验—容量—累计损失曲线。
6. 检查持久知识作用：分别清空短历史、清空策略修正、清空路由原型，使用配对的新流，分清参数知识与路由记忆的贡献。跨多个独立 W0 而不只改变部署种子。

固定有限精度容量面对任意无限新知识，不能无条件承诺所有旧情境永不退化；有价值的结果应说明结构可压缩性、辨识/访问条件及允许的遗忘和再学习代价。理论起点可选未知切换的线性 contextual bandit 或简单线性 MDP，先分析错误共享与结构压缩损失；神经环境中的经验置信不能冒充该理论的无条件结论。

## 8. 建议的核心贡献定位

优先把“依据跨情境改进证据，把局部在线知识转成可共享且真实释放容量的知识，并控制错误共享”作为一个主算法问题。创建、拆分、合并和替换从统一的预算与决策损失规则派生。需要提出可实现的估计器/结构算子、给出适用条件，并以同预算强对照证明它优于梯度聚类、固定共享和周期蒸馏。仅把已有模块拼成一个大框架仍不够。

树可以成为该算法在嵌套共享环境下的有效结构，也可能由证据支持改为稀疏图。这样的结构选择仍服务于原研究主题：预训练后的真实在线经验，持续进入有限、可复用、可组合的持久策略知识。
