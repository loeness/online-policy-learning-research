# 有界在线知识组织：三步验证规程

日期：2026-10-15。根据用户明确要求，执行静态整合、从零无标签辨识、最小在线闭环三个步骤。此前 P0 文档中“不启动下一阶段”的限制属于旧轮次；本轮获得新的执行授权。原 A/B/C1/P0 不修改、不重跑。这里的闭环是 C1 受控环境上的新机制实验，不代表已完成一般环境的 C2/C3 基准。

## 研究问题与成功标准

问题是在线奖励经验如何改变可持久保存的策略知识及其组织。树不是必须的结构。正式结果不能只与冻结策略比较：同预算独立量化、稀疏表示、简单共享和直接在线更新都是必要对照。固定容量既限制压缩后的策略知识，也限制路由、回放与可恢复优化状态；暂存区和候选评估成本另外计量，不以“临时”隐藏无限信息。

本轮固定一个 W0、原 C1 六个动作映射情境、三个可见 x 区域及 27 维策略修正坐标。该源输出基对动作置换有利。所有部署种子不是独立预训练种子。结果属于机制探索，不宣称 SOTA 或在线神经更新的普遍必要性。三个部署种子分别报告，多个依赖情境或 episode 不当作独立训练重复计算显著性。

## 第一步：静态整合

- 输入是既有成熟 hierarchical_output_mixer 的 s181、s193、s211 history 终点；将每个叶子的有效修正展开为 `A_leaf + C_family`，得到 6×27 矩阵。原有训练成本不算新增成本，但注明教师来自先前带家族先验的训练。
- 压缩不接收家族编号；情境隔离仅用于研究者评估。对照：dense float32、独立稀疏 Top-K、FP16、每行 int8、全局均值加稀疏残差、无监督双原型加稀疏残差、SVD 低秩。相同源基、原动作概率温度与探索率。
- 策略知识预算为 192、320、448、648、768 B。包括数值数组、形状、类型、索引、分配与尺度的实际编码字节；不适配某预算的方法标为不可行，不悄悄超支。另报 Python/文件封装字节与前向解码工作区。推理压缩不冒充含 Adam 的在线状态压缩。
- 编码的秩、非零数等只由预算和重构误差决定，不依据测试回报挑选。每候选每目标评估 32 个完整 episode；同 checkpoint×目标复用 reset/action 随机流，最大 64 步。保存每个 episode、编码文件和实际交互数。
- 门槛：相对于 dense，平均成功率损失不超过 5 个百分点且平均回报损失不超过 0.25，才称在该测量精度下保留效果。要支持“共享结构有额外价值”，共享方法还需在同预算下优于最佳独立稀疏/量化对照；只胜过 dense 的大小不能证明共享创新。
- Pilot：s181、4 episodes 的软件检查，排除于正式统计。第一步不做额外环境再训练，闭环负责验证继续更新。

## 第二步：从零无标签辨识

- 新路由器初始无部署情境原型，不输入任务编号、家族、切换时间或真实映射。只读行动前观测、此前动作/奖励/后继观测；由可见位移构造有界统计。墙边零位移作删失，不误当成一种新动作方向。
- 将没有尝试过的动作与已知动作产生矛盾区分；相似度、支持度和歧义分开记录。原型数最多 6，短历史窗口 8、32、64；不足以区分时允许保留不确定性。
- seeds 331、347、359，每个流含六情境各两次，随机次序、段长均匀取 384–640 步，切换可发生在 episode 内。研究者记录真值用于事后分析，learner 不可读取。
- 不同路由机制读取同一条由实际环境生成的行为流，隔离策略访问差异。行为是已有无标签 adaptive_assignment 控制器与随机探索混合；它使用源数据先验但不使用部署标签。这是路由诊断，不把它当作闭环方法的回报。
- 比较有支持度的原型发现、把低支持当新颖性的朴素方法、只保留近期窗口的转移预测。记录行动前下一转移预测误差/对数损失、路由覆盖、事后聚类一致性、重复分裂、原型替换、复现、变化延迟、误警和实际字节。窗口最优值不依据测试结果调回主闭环；主闭环预定窗口 32。
- 独立 active exploration 若没有实现与固定行为的公平对照，就明确列为未验证，不能从随机探索实验推出主动探测更优。

## 第三步：最小在线闭环

- 从相同 W0、零修正、空原型库开始。在一条不断切换的真实仿真流上同时发现情境并学习持久参数。正式 seeds 401、419、433，各 32,768 步；隐藏段长 1,024–2,048，切换可在 episode 内。相同 seed 的各臂共用外部切换安排，行为造成访问轨迹差异属于闭环本身。
- 采用同一 PPO 机制：rollout 256、batch 64、epochs 4、lr .003、entropy .06、gamma .98、GAE .95、clip .2、target KL .06；冻结 W0 actor 和 source basis，学习局部 27 维修正及共同 critic。路由在动作前确定，得到新事件后更新。路由槽复用必须具有 generation，旧 generation 的 actor 训练样本排除。
- 每 1,024 步把有界局部试用区提出的修正编码到持久策略知识包，actor 包上限 320 B。路由最多六原型，回放最多每原型 64 个观察（总 384），局部试用区最多 6×27 float32，所有工作区、optimizer 和 critic 字节如实报告。解码缓存不得拥有超出当前编码与当前有界试用的独立历史信息。整合后清除 residual optimizer moments；critic 状态计入共同持久成本。
- 对照包括冻结策略、单个共享修正直接在线更新、独立稀疏压缩、独立 int8、共享 SVD、证据门控候选选择。额外蒸馏臂只有在紧凑参数化真正可训练、实现检查通过且正式前明确规程时加入；否则完整记录未实现范围。
- 提议器尝试均值/双原型/低秩/独立量化。验证只使用有限的此前交互和近期 PPO 数据，不回到任意旧环境获取免费反事实。候选用有限 anchor 上的动作 KL 衡量压缩损失，局部经验优势估计辅助门控，旧情境 KL 容忍 .02。门控是经验启发式，不宣称安全保证或置信下界证明。所有候选、接受/拒绝、回退/替换、证据样本数、编码/验证时间均记录。
- 主指标是全部在线奖励/步、累计回报和时间序列；同时报成功率、策略参数更新数、门控决定、字节与墙钟。若只胜过冻结策略，不视为知识组织贡献成立。尤其比较 int8 与门控方法的收益和额外开销。
- 终点做清空短历史的配对重访：保留参数 vs 清除修正，每目标 8 episodes，路由可以继续吸收新事件，但不更新策略参数。两臂从克隆的路由状态开始，回报/交互均单独计费，不进入主训练流。此项不能替代长时间继续学习的稳定性验证。

## 算法来源与适用边界

- [Policy Distillation, arXiv:1511.06295](https://arxiv.org/abs/1511.06295)：以动作分布损失衡量/优化整合，而不只比较权重距离。
- [Progress & Compress, arXiv:1805.06370](https://arxiv.org/abs/1805.06370)：局部学习与慢整合两个阶段；本轮有严格候选和存储预算，没有复刻完整 P&C。
- [Modular Lifelong RL, arXiv:2207.00429](https://arxiv.org/abs/2207.00429)：共享知识与个别任务修正的组合；本轮没有它的全部模块搜索与离线 RL 过程。
- [DaCoRL, arXiv:2209.00347](https://arxiv.org/abs/2209.00347)：依据在线动力学证据发现/复用潜在情境；本轮用固定上限统计库，不是无限混合模型。
- [Restarted Bayesian Online Change-point Detection for Non-Stationary MDPs](https://proceedings.mlr.press/v232/alami23a.html)：历史证据与变化检测的思路；本轮简单检测器不继承其理论界。
- [SPIBB, arXiv:1712.06924](https://arxiv.org/abs/1712.06924)：缺乏支持时约束行为变化；本轮区分支持与新颖性，但没有满足其批量有限 MDP 安全保证的全部条件。

### 正式前补充 A（尚无本轮正式结果）

1. 在线闭环另加入已有 `adaptive_assignment` 无标签统计控制器，与其他臂共用隐藏切换安排和源策略。它是此环境的强对照，状态、交互与时间单独计量，不冒充神经参数更新。
2. 门控不能在刚用于拟合候选的同一批数据上称为独立验证。每个 1,024 步周期的前三个 256 步 rollout 用于 PPO，最后 256 步只采集留出验证数据，门控之前不在该段上更新策略；本轮所有神经学习臂遵守相同的 3/4 更新安排。验证流不提供额外免费交互，占总交互的 25%，也不能用于事后调测试超参数。保留数据的有限样本优势估计仍不是安全保证。
3. 本机当时可用 RAM 不足 1 GB；三个主要计算阶段顺序运行，torch 单线程。现有环境是 CPU 版 PyTorch，小网络运行不为使用 GPU 而更换依赖。

### 静态实验运行期间的公平性补充 B

代码审查发现初版独立稀疏基线给每行相同 K，而共享残差在所有行之间分配非零预算。这会把预算分配效果混入共享效果。因此保留原七方法结果，另增 `global_topk` 独立全局稀疏控制：直接对有效修正矩阵整体取幅值最大的非零项，不存共享项；预算、索引精度和评估流与共享残差一致。额外控制沿用全部三个 checkpoint、五档预算、32 episodes，输出到 `outputs/knowledge_static_global_control`，不以已有结果选择预算或 seed。

对 codec 额外要求：产生真实 16 字节二进制格式头和连续数值数组的 `.bin` 文件，检查文件字节数等于 `nbytes`；NPZ 只作可读交换封装，另列大小。原正式实验的数值编码和策略评估不变；添加二进制文件不会产生新环境交互。

### 静态结果后的机制补充 C（独立后续实验）

原七方法结果中低秩 SVD 在紧预算下有较大损失。为了区分“低秩容量不足”与“权重误差目标不适合策略压缩”，增加同秩、同字节的动作分布蒸馏；这是看到原结果后明确提出的后续机制实验，不并入原先冻结的主比较。全部三个教师、192/320/448 B 三档，不挑最好 seed。以 SVD 因子初始化，对源预训练数据中固定均匀抽取的 256 个观测各配六个教师路由（1,536 样本），优化教师与学生动作分布 KL，Adam lr=.01、256 次全批更新。固定同一温度/探索率，无环境奖励查询、无部署标签发现声明；路由仅为此隔离诊断的教师条件。拟合的状态覆盖来自源数据，是局限。测试沿用配对 32 episodes，另计交互，任何选择都不使用测试回报。保存最终因子而非挑选最佳测试迭代，临时 Adam、教师与缓存工作区另计。输出 `outputs/knowledge_distillation_control`。
