# 在线共享写入：当前算法、可检验主张与边界

本轮延续“预训练 + 部署后参数持续学习”的主题。核心待验证的是：在线经验怎样决定共享知识的写入和容量替换，而非树形容器本身是否有效。运行入口与冻结协议分别见 `WRITE_DECISION_PROTOCOL.md`、`WRITE_STREAM_PROTOCOL.md`、`WRITE_RECYCLE_PROTOCOL.md`、`WRITE_BUDGET_BASELINE.md`。本文件为实验后的解释，不改变这些协议或已有选择。

## 1. 实际结构

冻结预训练底座和从源策略得到的低维输出基。共享方法有六个局部槽、两个共享父模块；独立方法可以在同一 actor 字节上限下使用七个局部槽。没有自动多层树、DAG 或无限任务数据库。

策略输出的修正可写为

`correction(s, slot) = H [A(slot, band(s)) + C(group(slot))] P phi(s)`。

其中 `A` 每槽 27 个系数，`C` 每组 9 个系数；三个 band 是预设的空间分段。组由在线动力学及条件奖励统计推断，未分组时只使用局部修正。这个结构保留了较强先验，不能表述为从原始传感器自动发现任意潜在情境。

流式实验实际安装 int8 编码后再解码的 actor：六局部槽加两个父模块共 230 B，七个独立槽为 236 B。完整持久包另受 `W0 文件 + learner checkpoint <= 262144 B` 约束，包含优化器、路由、数值证据、随机状态及其余学习状态。日志和离线分析文件不作为部署时可访问知识。

这是 actor 上限与完整包上限的双重约束。两方法并非物理包字节恰好相等，也未证明在只限制总持久字节、不另限 actor 大小的情况下达到了最优分配；后续需要容量曲线。

## 2. 一次在线学习周期

每个完整周期有三个新鲜的 256 步 PPO 拟合 rollout，及一个不参与梯度更新的 256 步 holdout。局部学习率 0.003、共享学习率 0.001；独立快速对照的局部学习率为 0.004。新经验先形成当前策略的实际参数更新，再决定这次更新中多少进入共享模块。

联合试用法在周期内同时更新 `A` 和 `C`。设共享试用增量为 `D`：

- 接受：保留共享增量，其他绑定槽可以受其影响。
- 拒绝：恢复旧 `C`，将 `D` 加入当前槽各 band 的 `A`。当前学到的策略被保留，其余槽不接收这次共享写入。
- 投影：把 `D` 改为候选 `D'`，将 `D-D'` 补偿到当前 `A`。

这些等式在编码前保持当前有效参数不变；int8 舍入仍可能产生误差，因此另外记录。所有方法在提交周期结束时清空 actor Adam 动量，critic 状态保留。

共享检验分别使用当前新 holdout，以及每个旧驻留槽至多 24 条有实际行为概率、优势和 episode ID 的证据。旧证据不会当成新的 on-policy PPO 数据。投影构造证据与检验 episode 分开。检验是受 ESS、KL 和经验标准误限制的 clipped-advantage surrogate；它不是可靠的策略值置信下界，也没有单调改进保证。

当前策略得到补偿后本来就不变，因此不能用其 holdout 声称发生了跨情境迁移。冷父模块检验把当前局部修正设为零，考察父候选能否在当前情境提供信息；这仍不等于对未来陌生情境的迁移收益证明。未训练槽直接继承旧父模块的 `cold_prior_binding` 目前也没有经过收益 gate，属于明确保留的启发式缺口。

## 3. 路由与有限容量

受控阶段先给局部 route，只让分组和写入自动进行。容量阶段在 12 个情境竞争 6/7 个槽时先保留编号，再移除编号和切换提示。未知阶段只看可见的状态、动作、奖励和下一状态；128 步近期证据用于识别当前情境。未知时以基础策略与均匀动作混合获取信息，相关交互全计费。

短历史承担“现在是什么情境”的辨识；持久参数承担“此前学到了什么”的存储，两者不相互替代。近期窗口改为固定大小的增量统计，避免反复扫描历史。微基准的约 36 倍仅是该组件计算加速，不能视作整个学习算法的加速。

切换时会结束旧的同质 PPO 片段，避免把不同槽/代数的梯度混写。过短片段明确计作丢弃。评估在克隆中进行；每个目标从相同终点克隆，避免前一个目标的诊断淘汰影响下一个目标。评估数据不进入在线决策。

## 4. 已试过的组织替代

第一轮对比独立更新、仅动力学分组、动力学加奖励分组，以及严格 gate、放宽 gate、参考梯度投影、局部更新提升、试用后全部退回局部。验证种子选择两个候选，再在新种子固定运行。投影借鉴 A-GEM / PCGrad 的冲突限制思想，属于自定义适配，不能称为复现这些论文的算法。

第二轮补充固定容量缓存的 LRU、LFU、随机淘汰，并尝试累计驻留证据与父模块重组。累计证据只保留固定维度的充分统计，槽换代时清空。重组只有在两个父模块满载、周期边界到达且至少两个未分组驻留槽相容时执行：把被替换父模块的知识补偿到现存局部参数，再用新成员组成父模块。父模块选择目前是 LRU，不估计长期收益。

这保证了编码前驻留策略的即时等价，不能保证被淘汰情境未来重现时的恢复能力。共享知识从父模块转移到即将被逐出的局部槽，可能在之后丢失。未分组比例降低，也可能只是增加了写入耦合和重学，而非得到更好的知识组织。

第三轮独立 G0 对照取消付费 uniform probe，并把每个新 rollout 用于 PPO 拟合。known 阶段 51456 次训练交互，等于共享方法的 49152 次训练加 2304 次探测；unknown 阶段双方 49152 次。比较全流奖励 `sum(training+probe reward)/(training+probe steps)`，评估成本另列。训练更新数、计算和 known 每段停留时间不同，不能声称全部资源严格匹配。

## 5. 当前证据能够回答什么

因果对照“同样试用，但共享增量全部退回局部”能检验增益是否超出局部参数学习本身；它不能代替与简单奖励感知分组的比较。容量耗尽、未知情境和第二个环境生成器分别检验存储收益、辨识依赖与任务先验依赖；结果必须分别报告。

任何方法只提高总体在线奖励，都不足以证明自动组织是创新来源。要确立主张，还需在完整预算对照中展示：写入决策优于简单分组；存储满载时优于保留/重学；旧知识复现时具有收益；这些收益足以抵消验证、分组和结构维护成本。

## 6. 理论与后续算法的接口

容量—在线经验的理论动机可以支持研究问题，但不会自动推出上述参数化、分组规则或替换算法有效。经验 surrogate 也不能直接成为安全性定理。

下一步值得单独检验的是“组织操作的长期写入价值”：比较保留原父模块、把新知识仅留在局部、以及替换父模块三种选择，对后续自然复现收益和成本的影响。候选必须从有界保存的部署证据估值，证据不足可保留局部学习；不能向算法免费提供旧环境重置。仿真分叉只用于单独计费的观察者诊断。

收益预测、共享操作和遗忘成本需要各自消融，不能用更低的未分组比例替代最终策略质量。只有当这一决策在新种子、新生成器和不同容量下稳定有效时，才有依据将其作为独立方法贡献。
