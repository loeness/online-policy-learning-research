# 既有 lower 局部信号的独立确认

冻结日期：2026-10-19。方法、条件与学习参数不因本轮回报而调整。此前8-seed结果用于提出局部假设，不并入确认样本。

## 假设与范围

在既有导航动力学差异关系、old来源各2048步、新来源各1024步、history=future条件下，冻结的surrogate_lower能否优于一直keep？它是既有规则的确认，不是新增算法。original实际量级0.002 reward/step继续报告，不降低旧标准。

使用`configs/surrogate_lower_confirmation.json`。16个新seed仅按mapping扫描22101..22300，old family A/B各取前8个，均未在既有目录或配置中使用：22101、22102、22103、22104、22105、22106、22107、22108、22109、22110、22111、22112、22113、22114、22118、22121。不查看回报选seed。

每seed两种历史，共32共同前缀。两old source各2048步，随后8×1024历史；每case只展开与历史同名的未来比例，keep/replace/mean/none各12288步继续真实PPO。所有past-only规则在未来之前冻结；lower、frequency的价值直接引用它们选中的实际行动分支。没有对未选分支的在线反馈。prefix与模拟器/优化器/随机状态完整恢复；89B actor、262144B完整包上限、int8回写及actor Adam清空沿用原设置。

这只确认预先指定的局部条件，不声称对反转未来、奖励冲突、未知情境或自动知识结构成立。

## 估计与判读

每个seed先平均两历史的`R_lower−R_keep`，R为完整未来累计回报/12288。主估计对16seed等权平均。10000次配对cluster bootstrap，在A/B两个固定分层内分别抽8seed再等权合并；不把prefix/branch当独立样本。

- 均值>0且95%描述区间下端>0：独立确认局部正方向；同时报告正、负、持平seed数。
- 区间上端≤0：本cohort不支持正方向。
- 其余：不确定。
- 实际量级仍单列0.002：均值与区间均报告，方向确认不能代替达到该量级，更不能代替创新主张。

预声明次要对照为lower相对replace、mean、frequency；另列两历史和家族。多项结果只作描述，不根据最有利格子重定主检验。lower选择keep的持平样本纳入总体，不剔除。
