## 五个恢复 prefix 的选点、回退与字节别名

五个恢复项的 F64 与 U64 float64 候选 hash 均不同。V 选 F64；UG 选 U64 后执行同一 post-cast gate，但全部 gate 失败并回退到与 V 字节别名的包；UR 关闭该 gate，保存并评分 U64。锁文件未包含独立的 fallback_reason 字段，因此这里只报告 gate 失败和新训练 KL 对比，不推断其它原因。

## 解释、成本与边界

在这五条固定轨迹上，post-cast gate 使 UG 最终退回 V，所以 UG−V 没有可见效果；UR 绕过 gate 后旧 KL 在五项都下降，但 G_new 在三项下降、两项上升。这是有限候选/接纳路径的诊断信号，不能单独归因到 holdout 结果，也不是奖励或部署证据。11 个复用项必为零，完整 16 项均值因此稀释了仅来自 5 次恢复的变化。

campaign 观测 CPU 为 7.929755000000 秒，footer 前 wall 为 9.350686746649 秒；含未观测 footer 预留的上界分别为 12.929755000000 秒和 19.350686746649 秒。限额为 60 CPU 秒、120 wall 秒、64 MiB、0 新交互和 0 GPU。外部 SSH/传输/准入 CPU 未计且为 UNKNOWN。
